# Состав редакции для ревью

База: проверенный рабочий выпуск `d47fa51a554ed052e843ef2f3be91625eac3954c`

Публичный комплект содержит код рабочих модулей и обезличенную документацию. Он подготовлен отдельно от рабочей Git-истории

## Изменения состава

1. Исключены фотографии команды и архивные визуальные эксперименты со встроенными фотографиями
2. Прототипные массивы людей, задач, клиентов и целей в `public/js/dannye.js` очищены. Необходимые справочники сохранены; рабочие записи поступают через авторизованный API
3. Собранные внутренние принципы команды заменены искусственными примерами. Механика отображения принципов сохранена
4. Личные имена в сообщениях об ошибках и технических примерах заменены названиями ролей
5. Историческая миграция с личными логинами и проверочными значениями паролей исключена из публичного наполнения. Рабочие доступы не публикуются
6. Из собственных файлов удалены комментарии с историей коммуникации. Для JavaScript удаление комментариев проверялось по дереву синтаксиса; лицензионные сведения сторонних компонентов сохранены
7. Документы обезличены; рабочие ведомости и личные источники формулировок исключены. Числа в сценариях приёмки являются тестовыми примерами
8. Справочные метаданные готовности обновлены до базового выпуска; устаревшая ссылка на макет фокуса заменена действующим адресом

## Ограничение применения

Исторические файлы миграций отличаются от рабочего каталога. Этот репозиторий можно исследовать и проверять на чистом стенде; его нельзя автоматически подменять вместо каталога миграций существующей рабочей базы

Рабочие базы, вложения, резервные копии, журналы, сессии, переменные окружения, токены и личная переписка отсутствуют в комплекте. Пароли и ключи, которые создаются в тестах, относятся к искусственным временным стендам

Итоговые результаты дополнительной проверки очищенного комплекта приведены в `docs/verification.json`
