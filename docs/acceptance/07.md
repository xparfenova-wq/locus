# V. НАПРАВЛЕНИЯ

### К-59. Направлений восемь

**На экране:** во втором уровне меню восемь чипов: Synapt, Automy,
Automy Junior, Медиа, Наставничество, Платформа, владелец, Ассист+.
На экране Направлений восемь карточек

**Сервер:** GET /api/napravlenija отдаёт восемь элементов при фильтре
по активным

**Число:** SELECT COUNT(1) FROM napravlenija WHERE arhiv = 0 равно 8
и равно числу чипов на экране

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-60. У направления признак «есть клиенты»

**На экране:** у Личного бренда признак выключен, у остальных семи включён

**Сервер:** GET /api/napravlenija отдаёт у каждого элемента поле
est_klienty. У направления владелец false, у семи остальных true

**Число:** SELECT COUNT(1) FROM napravlenija WHERE est_klienty = 0 равно 1, и это kod =
'anton'

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-61. У направления без клиентов блоки воронки не показываются вообще

**На экране:** открыл владелец. Вкладок Клиенты и Рассылки нет
в линейке вкладок. Пустых блоков с нулями тоже нет: их нет совсем

**Сервер:** GET /api/napravlenija/anton отдаёт массив вкладок
без 'klienty' и без 'rassylki'. Прямой GET /n/anton/klienty
отдаёт 404

**Число:** у направления владелец 7 вкладок, у Медиа 9, разница 2. Длина массива vkladki в ответе равна числу вкладок на экране, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-62. Направления лежат одной таблицей с признаком активности

**На экране:** архивное направление не показывается в меню, но открывается
по прямой ссылке и работает

**Сервер:** GET /api/napravlenija?arhiv=1 отдаёт и активные, и архивные
Без параметра только активные

**Число:** PRAGMA table_info(napravlenija) содержит колонку arhiv
Второй таблицы под архивные направления нет

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-63. Метка направления это точка 7 пикселей цветом

**На экране:** в строке задачи и в строке человека перед названием точка
Инструмент разработчика показывает её размер 7px на 7px

**Сервер:** GET /api/napravlenija отдаёт у каждого элемента цвет точки
строкой токена, не произвольным hex в разметке

**Число:** вычисленные width и height элемента метки равны 7px, и число
различных цветов точек на экране равно числу направлений в ответе, то есть
восьми

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-64. Эмодзи в названии направления не ломают вёрстку

Эмодзи не запрещены, отдельного запрета нет. Проверяется не отсутствие,
а то, что они не портят раскладку

**На экране:** поставил эмодзи в начало названия направления. Чип меню
не стал выше остальных, строка списка не поехала, высота ряда прежняя

**Сервер:** GET /api/napravlenija отдаёт nazvanie как есть, без вырезания
символов

**Число:** высота чипа с эмодзи и без равна 24 пикселям в обоих случаях, разница 0 пикселей

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
