# VIII. ПОДЗАДАЧИ

### К-89. Подзадача это полноценная задача с родителем

**На экране:** открыл подзадачу 1431 по прямой ссылке. У неё своя карточка
со всеми полями задачи, она же видна строкой в общем списке задач

**Сервер:** GET /api/zadachi/1431 отдаёт тот же набор полей, что GET /api/zadachi/1428, плюс roditel_id = 1428

**Число:** подзадачи лежат в той же таблице zadachi, отдельной таблицы
podzadachi нет. SELECT COUNT(1) FROM zadachi WHERE roditel_id IS NOT NULL
больше нуля

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-90. Глубина ровно два уровня

**На экране:** в карточке задачи 1428 кнопка «Добавить подзадачу» есть
В карточке подзадачи 1431 такой кнопки нет

**Сервер:** POST /api/zadachi с roditel_id = 1431, у которой свой roditel_id,
отдаёт 400 с текстом про два уровня

**Число:** SELECT COUNT(1) FROM zadachi z JOIN zadachi r ON z.roditel_id = r.id
WHERE r.roditel_id IS NOT NULL равно 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-91. Шесть полей наследуются, семь нет

**На экране:** нажал «Добавить подзадачу» в задаче 1428. В открывшемся окне
заполнены направление, проект, клиент, ответственный, спринт, тип. Пусты
название, описание, дата, целевое число, цель, участники

**Сервер:** GET /api/zadachi/1428/zagotovka_podzadachi отдаёт ровно шесть
заполненных полей и семь пустых

**Число:** созданная подзадача имеет napravlenie, proekt_id, klient_id,
otvetstvennyj, sprint, tip равные значениям задачи 1428

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-92. Наследованное поле правится

**На экране:** в окне подзадачи сменил направление с Медиа на Synapt
и ответственного с себя на участницу Е. Сохранилось

**Сервер:** POST /api/zadachi с roditel_id = 1428 и направлением, отличным
от родителя, отдаёт 201

**Число:** SELECT napravlenie FROM zadachi WHERE id = 1431 не равно
SELECT napravlenie FROM zadachi WHERE id = 1428

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-93. Окно подзадачи закрывается молча, если ничего не ввели

**На экране:** нажал «Добавить подзадачу», ничего не трогал, нажал крестик
Окно закрылось без вопросов, задача не создалась

**Сервер:** ни одного POST /api/zadachi не ушло

**Число:** SELECT COUNT(1) FROM zadachi WHERE roditel_id = 1428 не выросло

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-94. Родитель предупреждает о незакрытой подзадаче

**На экране:** закрываю задачу 1428, у которой подзадача 1431 не сделана
Появляется «Одна подзадача не выполнена. Точно закрываем?» с кнопками
«закрыть» и «вернуться»

**Сервер:** PATCH /api/zadachi/1428 со статусом sdelano при открытой подзадаче
отдаёт 200 и поле preduprezhdenie с числом незакрытых подзадач. Закрытию
не препятствует

**Число:** число в предупреждении равно SELECT COUNT(1) FROM zadachi
WHERE roditel_id = 1428 AND status NOT IN ('sdelano','kogda_nibud')

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-95. Подзадача закрывается отдельно от родителя

**На экране:** закрыл подзадачу 1431, задача 1428 осталась в своём статусе

**Сервер:** PATCH /api/zadachi/1431 со статусом sdelano не меняет статус 1428

**Число:** SELECT status FROM zadachi WHERE id = 1428 не изменился

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
