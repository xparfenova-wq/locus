# IX. ЗАДАЧА В ЧУЖОМ НАПРАВЛЕНИИ

### К-96. Подзадача со сменённым направлением видна в двух местах по-разному

**На экране:** подзадача 1431 с направлением Медиа внутри задачи 1428
направления Automy Junior. В Automy Junior она видна подзадачей с отступом
внутри родителя. В Медиа она видна задачей верхнего уровня

**Сервер:** GET /api/zadachi?napravlenie=media содержит 1431 как строку
верхнего уровня. GET /api/zadachi?napravlenie=automy_junior содержит 1428, внутри
неё массив подзадач с 1431

**Число:** в обоих ответах 1431 это одна и та же строка таблицы, не копия

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-97. Над названием стоит кликабельная плашка родителя

**На экране:** открыл задачу 1431 в Медиа. Над названием строка
«Automy Junior, Запуск курса», она кликабельна и ведёт на /synapt/4827

**Сервер:** GET /api/zadachi/1431 отдаёт объект roditel с полями id,
nazvanie и napravlenie, а не только roditel_id

**Число:** nazvanie в объекте roditel равно
SELECT nazvanie FROM zadachi WHERE id = 1428

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-98. Задача считается в одном направлении, не в двух

**На экране:** в планёрке Медиа задача 1431 стоит своей строкой в блоке
своего типа. В планёрке Automy Junior она видна только в составе родителя
и в числах блоков не участвует

**Сервер:** GET /api/planerka?napravlenie=media&nedelja=43 содержит 1431
в массиве задач. GET /api/planerka?napravlenie=automy_junior&nedelja=43 не содержит
1431 в массивах задач блоков

**Число:** сумма задач всех блоков планёрки Junior плюс сумма блоков планёрки
Медиа равна SELECT COUNT(1) FROM zadachi WHERE sprint = 43
AND napravlenie IN ('automy_junior','media'), без двойного платежа

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-99. Исполнителю чужого направления приходит уведомление

**На экране:** участница Е видит колокольчик со счётчиком, внутри «администратор поставила
тебе задачу, Отрисовать баннеры для запуска, Automy Junior, Запуск курса»

**Сервер:** после POST /api/zadachi с otvetstvennyj = anya появляется запись
в GET /api/uvedomlenija у участницы Е

**Число:** SELECT COUNT(1) FROM uvedomlenija WHERE chelovek_id = 1
AND zadacha_id = 1431 равно 1, а не 2 при одном создании

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-100. При создании задачи виден список открытых задач проекта

**На экране:** создаю задачу с выбранным проектом 64, под полем названия
свёрнутая строка «в проекте 7 открытых задач». Нажал, раскрылся список

**Сервер:** GET /api/proekty/64/otkrytye_zadachi отдаёт массив из семи задач

**Число:** семь равно SELECT COUNT(1) FROM zadachi WHERE proekt_id = 64
AND status NOT IN ('sdelano','kogda_nibud')

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-101. Система не угадывает похожие задачи

**На экране:** ввёл название, похожее на существующее. Никакой подсказки
о похожести не появилось, есть только список задач проекта

**Сервер:** в API нет адреса вида /api/zadachi/pohozhie, сравнение названий
не производится

**Число:** не применяется, это критерий отсутствия

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
