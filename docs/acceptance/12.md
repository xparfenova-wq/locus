# X. ПУБЛИКАЦИЯ КАК ПРИЗНАК

### К-102. Публикации нет среди типов задачи

**На экране:** выбор типа показывает четыре значения: клиентская,
продуктовая, бизнесовая, внутренняя. Публикации среди них нет

**Сервер:** GET /api/spravochniki/spravochnik_tipov отдаёт массив из четырёх
значений. POST /api/zadachi с tip = publikacija отдаёт 400

**Число:** SELECT DISTINCT tip FROM zadachi даёт не больше четырёх значений

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-103. Галочка «это публикация» работает внутри любого типа

**На экране:** поставил галочку при типе «клиентская», раскрылись поля
публикации. Сменил тип на «внутренняя», галочка осталась, поля остались

**Сервер:** POST /api/zadachi с любым из четырёх tip и publikacija = true
отдаёт 201

**Число:** SELECT DISTINCT tip FROM zadachi WHERE publikacija = 1 содержит
больше одного значения на реальных данных

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-104. Четыре комбинации типа и публикации заводятся

**На экране:** завёл четыре задачи: пост для клиента (клиентская), пост
в канал Automy (бизнесовая), рассылка на 500 (бизнесовая), поздравление
с днём рождения (внутренняя). Все четыре сохранились

**Сервер:** четыре POST /api/zadachi отдали 201, каждый со своим tip
и publikacija = true

**Число:** SELECT tip, COUNT(1) FROM zadachi WHERE publikacija = 1
GROUP BY tip даёт три разных типа минимум

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-105. Галочка раскрывает ровно пять полей

**На экране:** поставил галочку, появились площадка, дата выхода, формат,
рубрика, аккаунт. Шестого поля нет

**Сервер:** GET /api/zadachi/1428 с publikacija = true отдаёт ploshadka,
data_vyhoda, format, rubrika, akkaunt_id

**Число:** `select count(*) from pragma_table_info('zadachi') where name in
('ploshadka','data_vyhoda','format','rubrika')` равно 4: поля публикации
лежат в самой задаче

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-106. Публикация считается в блоке своего типа и в блоке Контент

**На экране:** клиентская публикация видна в планёрке в блоке Клиенты
и в блоке Контент. В сводке сверху посчитана один раз

**Сервер:** GET /api/planerka?napravlenie=synapt отдаёт её id в массиве блока klienty
и в массиве блока kontent, а в объекте svodka она учтена один раз

**Число:** сумма чисел сводки равна
SELECT COUNT(1) FROM zadachi WHERE sprint = 43 AND napravlenie = 'media',
без удвоения публикаций

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
