# XV. ЧЕЛОВЕК УШЁЛ ИЗ КОМАНДЫ

### К-131. Человека нельзя удалить, можно деактивировать

**На экране:** в карточке человека команды кнопки «Удалить» нет, есть
«Деактивировать»

**Сервер:** DELETE /api/ljudi/dima отдаёт 405. PATCH с aktiven = false
отдаёт 200

**Число:** SELECT COUNT(1) FROM ljudi не уменьшается после деактивации

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-132. Деактивированный пропадает из выбора и из меню

**На экране:** в поле «На ком» Димы нет. В третьем уровне меню его нет
В прошлых задачах его имя видно

**Сервер:** GET /api/ljudi?komanda=1&aktiven=1 не содержит Диму
GET /api/zadachi отдаёт его имя в закрытых задачах

**Число:** SELECT COUNT(1) FROM zadachi WHERE otvetstvennyj = 'dima'
AND status = 'sdelano' больше нуля и не изменилось. Величина – пример рабочей базы, на тестовой не сверяется (отмечено 27.10)

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-133. При деактивации спрашивают про открытые задачи

**На экране:** появился экран «У Димы 12 открытых задач. Что с ними?»
с кнопками «перевести все на» и «разобрать по одной»

**Сервер:** PATCH с aktiven = false отдаёт 200 и объект otkrytye_zadachi
с числом 12

**Число:** 12 равно SELECT COUNT(1) FROM zadachi WHERE otvetstvennyj = 'dima'
AND status NOT IN ('sdelano','kogda_nibud')

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-134. Решение можно отложить, напоминание останется

**На экране:** закрыл экран, не выбрав ничего. В планёрке появилась строка
«12 задач без исполнителя»

**Сервер:** GET /api/planerka?napravlenie=synapt содержит блок с числом задач деактивированных

**Число:** `select count(*) from zadachi z join ljudi l on l.id = z.otvetstvennyj where
l.aktiven = 0 and z.status NOT IN ('sdelano','kogda_nibud')` равно числу в планёрке, расхождение
0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
