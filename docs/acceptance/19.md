# XVII. СТРАТЕГИЯ

### К-154. Стратегия на год, цели на кварталы внутри неё

**На экране:** вкладка Стратегия направления показывает год. Цели внутри
привязаны к кварталам этого года

**Сервер:** GET /api/napravlenija/synapt/strategija?god=2026 отдаёт текст
и массив целей четырёх кварталов

**Число:** все цели в ответе имеют period_id, начинающийся с 2026

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-155. Тезис стратегии имеет свой адрес

**На экране:** навёл на абзац стратегии, появилась ссылка. Скопировал,
открыл, страница прокрутилась к этому тезису

**Сервер:** GET /api/strategija/tezisy/X отдаёт один тезис

**Число:** число абзацев на экране равно `select count(*) from tezisy where napravlenie = 'synapt'`, абзацев без id равно 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-156. У тезиса кнопка «поставить цель», кнопки «поставить задачу» нет

**На экране:** у тезиса одна кнопка, она создаёт цель. Кнопки создания
задачи нет

**Сервер:** POST /api/strategija/tezisy/X/cel существует,
POST /api/strategija/tezisy/X/zadachi отдаёт 404

**Число:** SELECT COUNT(1) FROM celi WHERE tezis_id IS NOT NULL равно нулю:
поля такого нет

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-157. Под тезисом видны его цели с процентами

**На экране:** под каждым тезисом список целей, у каждой процент

**Сервер:** GET /api/napravlenija/X/strategija отдаёт тезисы с вложенным
массивом целей

**Число:** процент цели 9 на экране стратегии и на экране ОКР совпадает до одного знака после запятой, расхождение 0,0 процентных пункта

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-158. Внизу стратегии видно число тезисов без целей

**На экране:** строка «тезисов без целей: 2»

**Сервер:** ответ содержит bez_celej = 2

**Число:** 2 равно числу тезисов, на которые не ссылается ни одна цель

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
