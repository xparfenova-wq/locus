### К-160. Направление идёт первым в адресе, старая ссылка работает

**На экране:** адрес задачи это /synapt/4827, направление первым. администратор сменила направление задачи на media: адрес стал /media/4827, а старая ссылка /synapt/4827 открывает ту же задачу, не ошибку. В строке адреса при этом видно новое направление

**Сервер:** GET /synapt/4827 после смены направления отдаёт 301 на /media/4827, а не 404: номер задачи уникален, направление в адресе это подсказка человеку. GET /media/4827 отдаёт страницу с открытой карточкой

**Число:** переходов по старой ссылке успешно 3 из 3, ответов 404 равно 0. Номер задачи до и после смены направления тот же, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
