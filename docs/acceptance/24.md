# XXIII. ИСТОРИЯ ОТНОШЕНИЙ И КАСАНИЯ

### К-208. Касание это задача, отдельной сущности нет

**На экране:** в карточке человека касания видны как закрытые задачи
в ленте истории. Поля «следующее касание» нет

**Сервер:** в базе нет таблицы kasanija: касание как работа
создаётся через /api/zadachi с типом kasanie. Таблица
rassylka_kasanija это отметки общения в рассылках, не то же самое

**Число:** `SELECT COUNT(1) FROM sqlite_master WHERE type = 'table' AND name = 'kasanija'` равно 0: отдельной сущности «касание» нет, касание это задача с типом kasanie. Таблица rassylka_kasanija существует и к этому критерию не относится: это отметки общения в рассылках

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-209. Следующее касание это открытая задача по человеку

**На экране:** у человека с открытой задачей плашка о касании
не появляется. У человека без задач появляется

**Сервер:** GET /api/ljudi/212 отдаёт sledujushee_kasanie с id открытой
задачи или null

**Число:** sledujushee_kasanie не null тогда и только тогда, когда
SELECT COUNT(1) FROM zadachi WHERE klient_id = 212
AND status NOT IN ('sdelano','kogda_nibud') больше нуля

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-210. Лента истории собирается из двух источников

**На экране:** в карточке человека лента: закрытые задачи и смены стадий,
вперемешку по дате

**Сервер:** GET /api/ljudi/212/istorija отдаёт объединённый массив
с полем tip: zadachi или izmenenie

**Число:** число строк ленты равно сумме двух запросов: закрытых задач 12 плюс записей
журнала 7, итого 19, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-211. Отправка сообщения ставит стадию «написали»

**На экране:** закрыл задачу «Отправить КП Игорю», стадия сотрудничества
стала «написали», если была «не писали»

**Сервер:** PATCH задачи со статусом sdelano и признаком kasanie меняет
стадию сотрудничества

**Число:** `select count(*) from zhurnal where obekt = 'sotrudnichestvo' and pole =
'stadija' and kto = <кто закрыл>` выросло на 1

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-212. История отношений видна по каждому направлению отдельно

**На экране:** у человека два сотрудничества, в каждом своя лента

**Сервер:** GET /api/sotrudnichestva/X/istorija отдаёт только события
этого направления

**Число:** сумма событий по трём сотрудничествам 7 плюс 4 плюс 8 равно 19, столько же в общей ленте человека, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
