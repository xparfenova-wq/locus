# XXIV. ПОИСК

### К-213. Поиск один на весь Локус

**На экране:** поле поиска в шапке, ищет по задачам, людям, проектам,
целям и страницам Полезного

**Сервер:** GET /api/poisk?q=баннеры отдаёт объект с массивами
по каждому типу

**Число:** сумма длин массивов групп равна 23, столько же даёт `select count(*) from ljudi where imja_norm like '%сем%'`, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-214. Результаты сгруппированы по типу

**На экране:** результаты разделены заголовками: Задачи, Люди, Проекты,
Цели, Страницы

**Сервер:** ответ содержит ключи zadachi, ljudi, proekty, celi, stranicy

**Число:** на экране 2 группы из 4, в ответе все 4 ключа, из них 2 с пустыми массивами

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-215. Поиск находит по части слова

**На экране:** ввёл «бан», нашлись «баннеры»

**Сервер:** поиск по LIKE с обеих сторон или полнотекстовый

**Число:** число найденных равно `select count(*) from zadachi where nazvanie like
'%чекап%' or opisanie like '%чекап%'`, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-216. Поиск людей ищет по телефону и нику

**На экране:** ввёл последние четыре цифры телефона, нашёлся человек

**Сервер:** GET /api/poisk?q=4567 ищет в нормализованных контактах

**Число:** на наборе из 5 запросов «Семёнов», «семенов», « Семенов », «СЕМЕНОВ», «Семёнов  Игорь» все 5 из 5 дают один и тот же непустой массив, расхождение в составе id равно 0

### К-217. Архив в поиске за переключателем

**На экране:** по умолчанию архив не ищется. Включил переключатель,
архивные появились

**Сервер:** GET /api/poisk?arhiv=1 включает архивные записи

**Число:** без параметра 18 результатов, с параметром 42, то есть 18 меньше 42

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
