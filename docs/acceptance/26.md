# XXV. КОНТРАКТ API

### К-218. Правятся только переданные поля

**На экране:** поправил имя, остальное на месте

**Сервер:** PATCH с одним полем не трогает остальные колонки

**Число:** SELECT kontekst, osobennosti FROM sotrudnichestva WHERE id = <id> даёт прежние значения

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-219. Пакетная запись с защитой от повторов

**На экране:** мой Клод занёс семь задач из расшифровки, повторный запуск
того же файла не создал дублей

**Сервер:** POST /api/zadachi/paket принимает массив и ключ идемпотентности,
повтор с тем же ключом отдаёт прежний результат без записи

**Число:** после двух одинаковых запросов SELECT COUNT(1) FROM zadachi
вырос на семь, а не на четырнадцать

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-220. Ответ пакетной записи содержит три числа

**На экране:** «добавлено 7, обновлено 0, пропущено 0»

**Сервер:** ответ содержит dobavleno, obnovleno, propusheno и массив
ошибок по пропущенным

**Число:** dobavleno 12 плюс obnovleno 3 плюс propushcheno 0 равно 15, то есть длине переданного массива, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-221. У каждого человека свой ключ, у его Клода отдельный

**На экране:** в журнале видно «редактор А» или «Клод редактора А»

**Сервер:** запросы с ключом агента получают поле kto вида «Клод редактора А»

**Число:** SELECT DISTINCT kto FROM zhurnal содержит обе формы

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-222. Ошибка называет поле, а не «проверьте данные»

**На экране:** человек видит «Без названия задачу не сохранить»

**Сервер:** 400 содержит поле pole с именем проблемного поля и soobshenie
с человеческим текстом

**Число:** не применяется

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-223. Ответ «успех» только после фиксации записи

**На экране:** при обрыве связи «Не получилось сохранить»

**Сервер:** 200 отдаётся после COMMIT, а не до

**Число:** при каждом полученном 200 значение в базе изменено

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-224. Версия API в адресе или в заголовке

**На экране:** не применяется

**Сервер:** адреса начинаются с /api и содержат версию, старая версия
продолжает работать после выхода новой

**Число:** не применяется
