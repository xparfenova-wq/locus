# XXXI. ПАГИНАЦИЯ

### К-246. Списки режутся на страницы, бесконечной прокрутки нет

**На экране:** в списке людей внизу номера страниц и «дальше», прокрутка
до конца не догружает следующие строки сама

**Сервер:** GET /api/ljudi?stranica=2 отдаёт вторую страницу

**Число:** в списке ровно 50 строк, в ленте 20 записей

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-247. Счётчик показывает отфильтрованное из общего

**На экране:** без фильтра «340 записей», с фильтром по Медиа «12 из 340»

**Сервер:** ответ содержит vsego и najdeno

**Число:** najdeno равно 42, vsego равно 1518, то есть 42 меньше 1518

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
