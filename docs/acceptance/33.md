# XXXII. ЛЕНТА

### К-248. Тип содержимого ленты и технический тип записи не смешиваются

**На экране:** Доступны типы находок: инструмент, сервис, лекция, промт, книга, статья, кейс, пост, мысль. Запись без приставки показывается как «без типа». Фильтр по типу относится к содержимому находки, а не к разделу ленты.

**Сервер:** GET /api/lenta/potok?tip_nahodki=... принимает эти коды и bez_tipa; неизвестный код отклоняется. POST /api/lenta создаёт обычную находку с tip=zapis и текстом. Физическое поле tip имеет отдельный закрытый перечень zapis, refleksija, princip, novoe; произвольное значение этого поля не принимается.

**Число:** Канонический перечень типов содержимого содержит 9 значений. «Без типа» является отдельным пустым состоянием. Физический перечень lenta.tip содержит 4 значения. Количество строк отдельного SQL-справочника для типа содержимого не задаётся.

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-249. Лента идёт одной колонкой, не двумя

**На экране:** записи в колонке по центру, фильтры над лентой, а не сбоку

**Сервер:** нет

**Число:** ширина колонки 760px, на телефоне во всю ширину минус отступы

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-250. Автор показан фотографией

**На экране:** У записи показывается фотография автора из справочника людей. Размер соответствует общей шкале компонента аватара. При отсутствии фотографии место остаётся пустым; инициалы и выдуманная фотография не подставляются.

**Сервер:** GET /api/lenta/potok отдаёт chelovek_id автора. Фотография берётся из того же авторизованного справочника людей, который используется остальными экранами; дополнительная публикация личных фотографий через отдельный публичный API не требуется.

**Число:** На тестовом стенде есть автор с фотографией и автор без неё. Число фотографий и пустых мест соответствует этим данным. Производственное количество незаполненных фотографий не является нормативом.

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
