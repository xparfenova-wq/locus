# XXXIII. ВИЗУАЛЬНЫЕ РЕШЕНИЯ 20 ОКТЯБРЯ

### К-251. Круглых точек в интерфейсе нет

**На экране:** все метки направлений, статусов и подзадач квадратные
со скруглением. Круг остался только у аватарки и внутри диаграмм

**Сервер:** нет

**Число:** поиск по собранному CSS даёт border-radius:50% только
у классов аватарки

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-252. Диаграмм шесть видов, не одна полоса

**На экране:** в дизайн-системе показаны кольцо с засечкой, столбики периодов,
воронка, линия динамики, полоса долей, сетка плотности

**Сервер:** нет

**Число:** видов пустого состояния 6, каждый встречается минимум на 1 экране, неиспользованных 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-253. Список принципов закреплён при прокрутке

**На экране:** листаю длинный принцип справа, список слева остаётся на месте
и имеет свою прокрутку

**Сервер:** нет

**Число:** позиция списка не меняется при прокрутке на 1000px

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-254. График команды во всю ширину окна

**На экране:** сетка часов занимает всю ширину окна, не колонку 1100px

**Сервер:** нет

**Число:** ширина блока равна ширине окна при экране шире 1140px

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-255. Онбординг это инструкция, а не двенадцать шагов

**На экране:** отдельная страница с разделами и скриншотами, плюс четыре
живые подсказки на экранах создания задачи, спринта, подзадачи и ОКР

**Сервер:** PATCH /api/nastrojki отмечает показанные подсказки

**Число:** живых подсказок ровно 4, всплывающих шагов подряд 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
