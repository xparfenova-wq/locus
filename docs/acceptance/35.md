# XXXIV. СЧЕТА И ФИНМОДЕЛЬ

### К-256. Задача про оплату не создаётся вместе с платежом

**На экране:** администратор добавила платёж на 25 октября. В задачах ничего не появилось: ни «проверить оплату», ни «получить оплату». Чтобы задача была, она берёт шаблон «получить оплату» сама, и тогда проект, сумма и срок подставляются из платежа

**Сервер:** POST /api/platezhi создаёт только платёж. Число задач до и после запроса одинаковое. Задача появляется отдельным POST /api/zadachi/iz_shablona с shablon равным poluchit_oplatu и platezh_id

**Число:** `select count(*) from zadachi where proekt_id = 64` до и после добавления трёх платежей одинаково, разница 0. После одного нажатия шаблона выросло на 1, не на 3

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-257. Отметка «пришло» закрывает задачу по оплате, если она была создана

**На экране:** администратор создала задачу шаблоном «получить оплату», потом нажала «пришло» на самом платеже. Задача ушла из активных со статусом сделано. Если задачи не создавали, нажатие «пришло» просто закрывает платёж, и закрывать нечего

**Сервер:** POST /api/platezhi/{id}/prishlo переводит связанную задачу в sdelano, если она есть. Связь идёт по platezh_id задачи. При отсутствии такой задачи ответ тот же 200, без ошибки

**Число:** активных задач по этому платежу после оплаты 0. При отсутствии задачи код ответа 200 в 1 попытке из 1, ошибок 0. Это одно из двух исключений, где статус задачи меняется не человеком напрямую: человек нажал кнопку, просто на платеже

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-258. Локус отдаёт платежи и оплаты наружу

**На экране:** нет, это серверная ручка

**Сервер:** GET /api/dengi?period=2026-10 отдаёт платежи и оплаты по проектам

**Число:** сумма в ответе 120000,00 совпадает с суммой на экране до копейки, расхождение 0,00


### К-259. Плановая сумма может прийти извне

**На экране:** в проекте видно, что план посчитан в финмодели, а не вписан руками

**Сервер:** PATCH /api/proekty/{id} принимает plan_summa с пометкой источника

**Число:** `select stoimost from proekty where id = 64` отдаёт 120000, а сумма оплат равна `select sum(summa) from platezhi where proekt_id = 64 and oplachen_at is not null`; на экране подписано, какое из двух чисел показано, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
