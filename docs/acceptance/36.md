# XXXV. МЯЧ НА ЧЬЕЙ СТОРОНЕ

### К-260. Дней без общения считается само

**На экране:** у сотрудничества с Игорем по Synapt строка «3 дня без
общения». Поля для ручного ввода этого числа нет

**Сервер:** GET /api/sotrudnichestva/{id} отдаёт dnej_bez_obshenija,
считается от последнего события: закрытая задача, смена стадии,
отправленная рассылка, отметка общения

**Число:** число на экране равно `select julianday('now') - julianday(max(kogda)) from
zhurnal where obekt_id = 212`, расхождение 0 дней

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-261. Отметить общение обнуляет счётчик

**На экране:** поговорили голосом, нажала «отметить общение». Счётчик
стал 0 дней, в истории появилась запись «общение, отмечено вручную»

**Сервер:** POST /api/sotrudnichestva/{id}/kasanie без тела

**Число:** было 21 день, стало 0, запись в журнале одна

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-262. Давно не общались считаются по норме направления

**На экране:** у Synapt норма 14 дней. Сотрудничество, где 21 день
без общения, попало в фильтр «давно не общались» и в блок «давно не общались»
на планёрке

**Сервер:** норма берётся из карточки направления, поле norma_tishiny

**Число:** при норме 14 дней у Synapt и 30 у Медиа в списке 3 строки Synapt со сроком
больше 14 и 1 строка Медиа со сроком больше 30; строк, нарушающих своё
правило, 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-263. Механизма «мяч на чьей стороне» нет

**На экране:** ни на одном экране нет состояния «мяч у нас» или «мяч
у клиента». Кнопки «я ответил» нет

**Сервер:** ручки /api/zhurnal с направлением входящее или исходящее
не существует

**Число:** поиск по интерфейсу слова «мяч» даёт ноль совпадений

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-264. Бот ничего не решает сам

**На экране:** нет

**Сервер:** список для рассылки отдаёт Локус через GET /api/zhurnal, бот только шлёт

**Число:** правил про сроки и важность в настройках бота 0: только три поля из К-240
