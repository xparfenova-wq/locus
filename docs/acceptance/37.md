# XXXVI. ПЕРИОДЫ ЦЕЛЕЙ И ДЕКОМПОЗИЦИЯ

### К-265. Переключатель периода меняет окно, а не цель

**На экране:** переключил квартал на месяц, цель та же, число факта изменилось

**Сервер:** GET /api/celi?period_id=2026-Q4 отдаёт тот же id цели с другим окном факта

**Число:** id цели до и после переключения одинаков, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-266. Цель верхнего уровня можно разбить по периодам ниже

**На экране:** у годовой цели кнопка «разбить по кварталам», появляются четыре строки

**Сервер:** POST /api/celi/{id}/dekompozicija создаёт дочерние цели

**Число:** при родителе 500 и трёх детях по умолчанию 167, 167, 166, сумма равна 500, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-267. Расхождение показывается, но не блокирует

**На экране:** сумма кварталов меньше года, строка «не хватает 150 тыс.», сохранить можно

**Сервер:** сохранение проходит при любой сумме

**Число:** при родителе 500 и сумме детей 480 ответ отдаёт raznica равное 20

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-268. Верхняя цель не пересчитывается от нижних

**На экране:** поправил квартал, год остался прежним

**Сервер:** PATCH дочерней цели не трогает родительскую

**Число:** план родителя равен 500 до и 500 после правки ребёнка, разница 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
