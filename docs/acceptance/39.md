# XXXVIII. ФОКУС

### К-281. Сессия засчитывается только доведённая до конца

**На экране:** остановил таймер на середине, счётчик не вырос

**Сервер:** Запуск создаёт сессию через POST /api/fokus/start. Завершение или остановка передаются через POST /api/fokus/stop; сервер проверяет активное время и паузы. Ранняя остановка сохраняется как прерванная и не увеличивает счётчик

**Число:** `select count(*) from fokus_sessii where zachtena = 0` больше 0, но в счётчике таких сессий 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-282. Привязка к задаче необязательна

**На экране:** можно стартовать без выбора задачи, сессия всё равно считается

**Сервер:** zadacha_id может быть пустым

**Число:** Счётчик за выбранный день или неделю равен числу завершённых зачтённых focus-сессий этого человека в границах периода. Условия: chelovek_id=:me AND rezhim='fokus' AND zachtena=1 AND konec IS NOT NULL AND konec<>''. Привязка zadacha_id на включение в личный счётчик не влияет; перерывы исключены по К-401.

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-283. Время из сессий видно в карточке задачи

**На экране:** «на неё потрачено 4 сессии, 1 ч 40 мин»

**Сервер:** GET /api/zadachi/{id} отдаёт сумму привязанных сессий

**Число:** равно `select count(*) from fokus_sessii where zadacha_id = 1428 and zachtena = 1 and rezhim = 'fokus' and konec IS NOT NULL and konec <> ''`, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-284. Рейтинг по умолчанию выключен

**На экране:** человек не появляется в общем списке, пока сам не включит

**Сервер:** pokazyvat_v_rejtinge_fokusa по умолчанию false. GET /api/fokus/rejting включает только добровольно разрешивших показ участников с зачтёнными focus-сессиями выбранной ISO-недели.

**Число:** Число участников API-рейтинга равно числу включивших показ людей с хотя бы одной завершённой зачтённой focus-сессией за выбранную неделю. Включённая настройка без сессий не создаёт пустую строку. Отображение блока при недостаточном числе участников проверяется отдельно.

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-285. Рейтинг недельный и обнуляется

**На экране:** в понедельник список пустой, набирается заново

**Сервер:** GET /api/fokus/rejting?nedelja=43

**Число:** `select count(*) from fokus_sessii where nachalo < date('now','-7 day')` больше 0, при этом в текущем рейтинге таких сессий 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
