# XL. ИНСАЙТЫ ЛОКУСА

### К-289. Инсайт про третий перенос появляется ровно на третьем

**На экране:** задачу перенесли дважды, инсайта нет. Перенесли третий раз, появился

**Сервер:** число записей о переносе в журнале равно 3

**Число:** номер шага в ответе равен 3, число шагов до него 2

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-290. Не больше пяти инсайтов одновременно

**На экране:** шестой и дальше спрятаны под кнопкой «ещё»

**Сервер:** GET /api/insajty отдаёт все, экран показывает пять

**Число:** число видимых строк равно 5, шестая появляется только после прокрутки

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-291. Инсайт исчезает сам, когда причина ушла

**На экране:** закрыли задачу, инсайт про неё пропал без действий человека

**Сервер:** инсайты пересчитываются при чтении, не хранятся как записи

**Число:** инсайтов, причина которых исчезла, равно 0 после ночного прогона

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-292. «Не сейчас» прячет ровно на неделю

**На экране:** нажал, инсайт исчез. На восьмой день он снова есть

**Сервер:** otlozhen_do = сегодня плюс 7 дней

**Число:** окно равно 7 дням: при 6 днях инсайт не показан, при 7 показан

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-293. Медиана считается запросом, не константой

**На экране:** «обычно закрывает 8» меняется, когда меняются данные

**Сервер:** медиана закрытых за восемь недель считается при каждом чтении

**Число:** после роста темпа вдвое показанная цифра меняется не позже 7 дней: замер на 8-й день отличается от исходного

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-294. Формулировка через работу, не через человека

**На экране:** «у участницы Е 14 задач, обычно закрывает 8» вместо «участница Е не справляется»

**Сервер:** шаблоны текстов в одном месте, проверяются при сборке

**Число:** оценочных слов про людей в шаблонах 0 по всем 23 шаблонам

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
