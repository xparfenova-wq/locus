# XLI. ГРАФИК РАБОТЫ КОМАНДЫ

### К-295. Сетка часов 8-21 по дням недели

**На экране:** строка на человека, столбцы по часам, клик отмечает занятость

**Сервер:** PATCH /api/grafik с массивом часов

**Число:** 14 часов в сутках, 7 дней

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-296. «Как на прошлой неделе» копирует предыдущий график

**На экране:** нажал, сетка заполнилась как на прошлой неделе

**Сервер:** POST /api/grafik/kopirovat?iz=42&v=43

**Число:** у скопированных дней совпадают часы, интервалы, отметка «не работаю» и заметка. id, год, неделя и версия относятся к новой записи. Уже заполненные дни новой недели сохраняются. Исходный график не меняется

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-297. Подсказка при постановке задачи

**На экране:** у человека 16 часов на неделе и 7 задач, при выборе его исполнителем видно предупреждение

**Сервер:** GET /api/ljudi/{id}/zagruzka отдаёт часы и число задач

**Число:** после показа подсказки POST задачи отдаёт 201 в 3 попытках из 3, ни одного кода 409 и 422

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-298. Чекбокс «не работаю на этой неделе»

**На экране:** отметил, строка стала серой, часы ноль

**Сервер:** ne_rabotaju = true

**Число:** число подсказок по этому человеку равно 0 при 3 загрузках из 3

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
