# XLII. ТЕЛЕФОН

### К-299. Ни один экран не вылезает за ширину окна

**На экране:** на 390px нет горизонтальной прокрутки страницы

**Сервер:** нет

**Число:** `document.documentElement.scrollWidth` равен `window.innerWidth`, расхождение 0 пикселей

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-300. Карточки открываются полным экраном

**На экране:** на телефоне карточка задачи занимает весь экран, не попап в углу

**Сервер:** нет

**Число:** при окне 390 ширина карточки равна 358 пикселям: 390 минус по 16 с каждой стороны, расхождение не больше 2 пикселей

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-301. Меню прокручивается вбок, не переносится

**На экране:** уровни меню листаются горизонтально, высота шапки не растёт

**Сервер:** нет

**Число:** высота шапки на 390 не больше 112 пикселей, то есть двух рядов по 56

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
