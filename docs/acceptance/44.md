# XLIII. МИГРАЦИИ, СКОРОСТЬ, ПОЧИНКА

### К-302. Миграция не теряет данные

**На экране:** после обновления схемы все записи на месте

**Сервер:** миграция в транзакции, при ошибке откат

**Число:** `select count(*) from zadachi` до и после миграции равно 1842 в обоих замерах, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-303. Список из 1518 человек открывается меньше чем за секунду

**На экране:** переход в Люди без ожидания

**Сервер:** индексы на поля фильтрации, пагинация по 50

**Число:** ответ API меньше 400 мс на 1518 записях

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-304. Сломанный экран не роняет остальные

**На экране:** ошибка в одном блоке, остальная страница работает

**Сервер:** ошибка блока возвращает пустой блок с пометкой, не 500 на страницу

**Число:** при ответе 500 на один из 6 блоков отрисовано 5 из 6, пустых экранов 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-305. Вход для агентов отдельный от человеческого

**На экране:** нет

**Сервер:** токен агента не даёт доступа к сессии человека и наоборот

**Число:** вход даёт 2 ответа 200 из 2 попыток: по ссылке из почты и по коду из приложения. При отключённом одном втором вход проходит, 1 из 1
