# XLIV. РЕШЕНИЯ 21 ОКТЯБРЯ, ФУНКЦИОНАЛЬНЫЕ

### К-306. Галочка закрывает задачу, крестик сворачивает карточку

**На экране:** галочка слева от названия переводит задачу в сделано
Крестик справа сверху закрывает карточку, не трогая статус

**Сервер:** галочка шлёт PATCH со статусом, крестик ничего не шлёт

**Число:** действий в карточке ровно 2: отметить сделанной и закрыть проект; кнопок с текстом «Закрыть задачу» 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-307. Сводка направлений это отдельный раздел

**На экране:** сводка по восьми направлениям живёт сама по себе, страница
одного направления открывается отдельно

**Сервер:** GET /api/napravlenija отдаёт сводку, GET /api/napravlenija/{id} одно

**Число:** адресов 2: /moe и /zadachi, каждый отдаёт свой документ. Число блоков обоих экранов на одной странице равно 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-308. По умолчанию открывается последнее направление

**На экране:** зашёл в направления, открылось то, где работал последним

**Сервер:** последнее открытое хранится в настройках человека

**Число:** у администратора по умолчанию synapt, у участницы Б media: `select count(distinct vid_zadach) from nastrojki` больше 1. Величина – пример рабочей базы, на тестовой не сверяется (отмечено 27.10)

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-309. Цели стратегии показаны чипами, не полосками

**На экране:** у тезиса стратегии процент в чипе, прогресс-бара нет

**Сервер:** нет

**Число:** полос прогресса в блоке стратегии ноль

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-310. Поиск внутри Людей это тот же общий поиск

**На экране:** строка поиска в Людях ищет по тем же полям, Cmd+K открывает
общий поиск поверх

**Сервер:** один эндпоинт поиска, не два

**Число:** строк поиска на экране ровно 1, запросов к /api/poisk на один ввод 1, других поисковых адресов в сети 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-311. Третий уровень меню только там, где есть что фильтровать

**На экране:** панель людей видна в Моём пространстве, Задачах, Людях
В Планёрке, Полезном, ОКР, Направлениях, Проекте, Кабинете, Поиске её нет

**Сервер:** нет

**Число:** панель людей есть ровно на 3 экранах из 14

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
