# XLV. СОЦСЕТИ: ПЕРЕНОС РАБОТАЮЩЕЙ МЕХАНИКИ

Раздел про то, что уже собрано в текущей версии Локуса. Приёмка здесь
означает «перенесено без потерь», а не «написано заново»

### К-312. Данные соцсетей перенесены полностью

**На экране:** открыть раздел Соцсети: 7 аккаунтов, 541 публикация, 10 312 снимков публикаций, 349 снимков аккаунтов

**Сервер:** GET /api/akkaunty отдаёт 7 записей с aktiven = 1. GET /api/publikacii отдаёт 541

**Число:** SELECT COUNT(*) FROM akkaunty WHERE aktiven = 1 равно 7, FROM publikacii равно 541, FROM zamery_publikacij равно 10312, FROM zamery_akkauntov равно 349. Величина – пример рабочей базы, на тестовой не сверяется (отмечено 27.10)

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
