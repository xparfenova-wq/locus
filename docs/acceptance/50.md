# XLIX. МАТЕРИАЛЫ И ДОКУМЕНТЫ

### К-951. Материалы и документы это два отдельных блока, а не один список

**На экране:** на карточке проекта Synapt человек видит два раздела с разными заголовками: Материалы и Документы. У каждого свой счётчик в заголовке: Материалы 7, Документы 3. Между ними нет общего переключателя и нет вкладок внутри одного блока

**Сервер:** GET /api/proekty/synapt/materialy отдаёт объект с двумя массивами: materialy и dokumenty. Каждый элемент несёт obekt со значением material или dokument, никакой элемент не попадает в оба массива

**Число:** в ответе len(materialy) = 7, len(dokumenty) = 3, пересечение по id пустое. SELECT tip_fajla, count(*) FROM materialy WHERE napravlenie = 'synapt' GROUP BY tip_fajla возвращает ровно две строки

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-952. У блока материалов и у блока документов разный набор колонок

**На экране:** в материалах человек видит название, кто добавил, когда добавил. В документах название, тип, номер, дата, кто добавил, когда добавил. Колонки тип, номер и дата в блоке материалов отсутствуют полностью, не пустыми ячейками

**Сервер:** GET /api/proekty/synapt/materialy: элемент materialy содержит nazvanie, vid_istochnika, kto_dobavil, sozdano. Элемент dokumenty дополнительно содержит tip, nomer, data_dokumenta. Полей tip, nomer, data_dokumenta в элементах materialy нет

**Число:** у любого элемента materialy проверка 'tip' in element = false. В таблице списка материалов 3 колонки данных, в таблице документов 6

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-957. Загрузка файла до 50 МБ, исполняемые отклоняются

**На экране:** в блоке Материалы проекта Synapt администратор жмёт добавить, выбирает Загрузить файл, берёт макет-главной.psd размером 47,3 МБ. Видит полосу прогресса, после неё запись появляется в списке с названием макет-главной.psd и размером 47,3 МБ. Попытка приложить setup.exe даёт отказ с текстом «исполняемые файлы не принимаются»

**Сервер:** POST /api/materialy multipart с полем file возвращает 201 и id материала, razmer_bajt, tip_fajla, nazvanie. Форматы .psd .zip .heic .mp4 .dwg и файл без расширения принимаются одинаково. Расширения exe, app, sh, bat, cmd отдают 400 с kod = ispolnjaemyj_fajl, проверка идёт и по расширению, и по tip_fajla

**Число:** лимит в конфиге MAX_UPLOAD_BYTES = 52428800. Файл 52428800 байт проходит и получает 201, файл 52428801 байт получает 413. Проверка пройдена на шести разрешённых форматах из шести и на пяти запрещённых из пяти: ни один исполняемый не загрузился. `select count(*) from materialy where fajl like '%.exe' or fajl like '%.sh' or fajl like '%.bat' or fajl like '%.cmd' or fajl like '%.app'` равно 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
