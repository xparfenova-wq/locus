### К-989. Первая линейка чипов направления видна сразу при открытии раздела Люди

**На экране:** администратор открывает Люди, под шапкой первая линейка чипов: все, Synapt, Automy, Медиа, Наставничество, каждый чип с подписью направления без счётчика; активное направление залито, остальные контурные; выбран один чип, два направления одновременно не выбираются

**Сервер:** GET /api/ljudi/srezy?facet=napravlenie отдаёт массив napravlenija с полями id, nazvanie, slug, porjadok, arhiv=false; порядок по porjadok возрастанием; направления с arhiv=true в линейку не попадают

**Число:** запрос select count(*) from napravlenija where arhiv=false даёт 4, в линейке 4 чипа плюс чип все, итого 5 элементов. Величина – пример рабочей базы, на тестовой не сверяется (отмечено 27.10)

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

**Число:** select COUNT(DISTINCT chelovek_id) from sotrudnichestva where napravlenie=:synapt совпадает с vsego в ответе

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-991. Первая линейка чипов роли: лид, клиент, реферал

реферал. Архива среди них нет, он отдельным переключателем. Чипы роли
отделены от чипов направления зазором 24 пикселя без разделителя

**Сервер:** GET /api/ljudi?dostup=lid,klient отдаёт людей, у которых есть
сотрудничество с такой ролью. Поле primenennye_filtry.rol это массив
Допустимые значения lid, klient, referal. Значение arhiv даёт 422
с перечнем допустимых

**Число:** SELECT COUNT(DISTINCT chelovek_id) FROM sotrudnichestva
WHERE rol IN ('lid','klient') AND arhiv = 0 равно итоговому числу
