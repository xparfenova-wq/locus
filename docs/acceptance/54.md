# LIII. ПОВТОРЯЮЩИЕСЯ ЗАДАЧИ И ИТОГИ ДНЯ

### К-1247. Повторение это свойство задачи, задача остаётся одна

**На экране:** администратор включает повторение у задачи разобрать входящие. В списке по-прежнему одна строка с бейджем повтор. Ни в этом дне, ни в следующих вторая строка той же задачи не появляется

**Сервер:** PATCH /api/zadachi/1428 с povtorjaetsja: true и chastota: kazhdyj_den отдаёт 200. GET /api/zadachi?data=любой день следующей недели отдаёт ту же задачу с тем же nomer 1428, не копию с новым номером

**Число:** `select count(*) from zadachi where nazvanie = 'разобрать входящие'` равно 1 и на следующий день, и через неделю. Число строк в zadachi после включения повторения не изменилось: было N, стало N. Величина – пример рабочей базы, на тестовой не сверяется (отмечено 27.10)

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

### К-1248. Выполнение за день это отметка, а не новая задача

**На экране:** администратор отмечает задачу сделанной в четверг. Строка становится сделано. В пятницу та же строка снова в плане, вчерашняя отметка на месте

**Сервер:** POST /api/zadachi/1428/otmetki с data: 2026-10-23 и status: sdelano отдаёт 201. GET /api/zadachi/1428 в пятницу отдаёт status: v_plane и массив otmetki с записью за четверг

**Число:** `select count(*) from otmetki_povtora where zadacha_id = 1428` равно 1 после одной отметки. `select count(*) from zadachi where nomer = 1428` остаётся 1

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое

**Число:** `select count(*) from zhurnal where obekt_id = 1428 and pole = 'data'` равно 0 за период без ручных правок

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
