**На экране:** администратор открывает карточку шаблона, кнопки скопировать ссылку в ней нет, адрес браузера при открытии карточки меняется только на служебный вид вкладки Полезного

**Сервер:** метода получения публичного адреса шаблона в API нет, GET /api/shablony? принимает только kod

**Число:** кнопок копирования ссылки в карточках шаблонов 0 из 10

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
