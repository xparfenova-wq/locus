# LVII. ВОРОНКА И ОСТАВШИЕСЯ ПОЛЯ

### К-1520. Воронка считается по журналу изменений

**На экране:** в направлении Synapt блок «Воронка» за квартал: лиды 47,
клиенты 12 с подписью 26% от лидов, проекты 18, оплачено 9 с подписью
50% от проектов

**Сервер:** GET /api/napravlenija/synapt/voronka считает по таблице zhurnal:
переходы rol на klient за период, а не текущие роли

**Число:** число клиентов в воронке равно `select count(*) from zhurnal where pole =
'rol' and stalo = 'klient' and kogda >= '2026-10-01'`, расхождение 0

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
