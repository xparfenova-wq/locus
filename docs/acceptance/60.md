# LXII. КЛЮЧЕВАЯ ЗАДАЧА

### К-1716.Ключевая задача: пометка, место в списке, фильтр

**На экране:** В карточке создания рядом с «публикацией» тумблер «ключевая», в карточке задачи строка «ключевая» с тумблером. В списках Задач, Пространства и Планёрки ключевая задача стоит первой в своей группе, название плотнее (500), в подписи слово «ключевая», значков и цвета нет. На Задачах чип «ключевые» с числом отбирает только их

**Сервер:** POST /api/zadachi с kljuchevaja: true создаёт ключевую задачу, PATCH /api/zadachi/{номер} с kljuchevaja: false снимает пометку, GET /api/zadachi?kljuchevaja=1 отдаёт только ключевые, сводка отдаёт kljuchevye

**Число:** SELECT count(*) FROM zadachi WHERE kljuchevaja NOT IN (0, 1) AND kljuchevaja IS NOT NULL равно 0

**Две ширины:** проверяется на 1440 и на 390: на телефоне тумблеры «публикация» и «ключевая» стоят второй строкой под сегментами и не выходят за край карточки
