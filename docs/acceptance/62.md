## Уточнение21.11.2026 кК-283

Уточнение21.11.2026:1428 в этой SQL-формуле — внутренний id задачи, а не её номер в адресе. Минуты берутся из активного времени без пауз и только из завершённых фокусных сессий. Невозможное старое время остаётся неизвестным. Агрегат показывает всё время по задаче; возврат из таймера обновляет его, сохраняя набранный комментарий
