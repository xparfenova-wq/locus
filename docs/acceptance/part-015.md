**На экране:** в блоке Synapt роль клиент нарисована плашкой с темным фоном и светлым текстом. Приводит клиентов нарисовано серым текстом без фона, без рамки, без полоски слева. Две плашки рядом не стоят ни в одном блоке

**Сервер:** сервер отдаёт только значения, оформление на клиенте. В ответе есть privodit_klientov булевым, не строкой с подписью

**Число:** на экране в шапке блока число элементов с фоном плашки равно 1. Контраст серого текста к фону не ниже 4,5 к 1, замеряю пипеткой по контрасту

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
