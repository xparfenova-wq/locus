**Сервер:** GET /api/ljudi/{id} под таким доступом отдаёт privodit без ключей zarabotano и k_vyplate, с полем skryto массивом из этих двух имён. Суммы не приходят на клиент вовсе

**Число:** в ответе поиск подстроки 190000 даёт 0 вхождений. В разметке страницы поиск 190 000 даёт 0 вхождений
