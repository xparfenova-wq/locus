**Сервер:** тот же POST /api/materialy multipart, дополнительных мобильных маршрутов нет. Для фото с камеры сервер принимает heic и jpeg без конвертации на клиенте, nazvanie формируется по дате съёмки, если устройство не дало имя

**Число:** загрузка фото 4,1 МБ через мобильную сеть завершается успешно: 1 из 1. Прогресс обновляется не реже раза в секунду. Отмена на 50% прерывает запрос и не создаёт записи: SELECT count(*) FROM materialy после отмены равен значению до начала
