**На экране:** услуга агент убрана в архив. В новом проекте Synapt раскрываем список услуги, агента в нём нет. Открываем старый проект, где агент стоял, в его поле по-прежнему написано агент, рядом серая пометка в архиве, поле не очистилось и ошибки не показывает

**Сервер:** GET /api/proekty/{id}/dostupnye_uslugi для нового проекта Synapt не содержит id услуги агент. GET карточки старого проекта отдаёт usluga_id услуги агент и usluga_arhiv=true

**Число:** SELECT count(*) FROM proekty WHERE usluga_id=(SELECT id FROM uslugi WHERE nazvanie='агент') равно 3 до архивации и 3 после. Величина – пример рабочей базы, на тестовой не сверяется (отмечено 27.10)

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
