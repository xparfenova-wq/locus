После переименования через один адрес `select count(distinct nazvanie) from dokumenty where id = {id}` равно 1, расхождение 0. Файл на диске один: `select count(distinct fajl) from dokumenty where id = {id}` равно 1

**Две ширины:** проверяется на 1440 и на 390, поведение одинаковое
