# ЧАСТЬ I. ЧТО ТАКОЕ ЛОКУС

## Одна фраза

Locus это фокус на важном через существование общей карты с задачами, людьми, целями
и динамикой по их достижению

Слово заложено как «держим фокус на важном»

## Пять задач продукта, по важности

| № | Задача | Про что |
|---|---|---|
| 1 | **ОКР** | только цели: поставить, декомпозировать, видеть прогресс |
| 2 | **Трекинг** | только задачи: занести и не забыть |
| 3 | **Динамика** | планёрки: как задачи недели двигают цели |
| 4 | **Карта клиентов** | когда взаимодействовали, когда вернуться, по какому проекту |
| 5 | **Хранилище контекста** | карточка клиента, контекст проекта, файлы |

ОКР не спорит с трекингом: цели отдельно, задачи отдельно, связь между ними
живёт в Динамике

### Где показывается панель людей

Решение 21 октября: третий уровень меню не везде. Он фильтр, и живёт только там,
где есть что фильтровать по человеку:

```
есть      Моё пространство, Задачи, Люди
нет       Планёрка, Полезное, ОКР, Направления, Проект, Кабинет, Поиск
```

**Планёрка:** людей нет, она собирается по направлению за спринт. Остаются
направления и период справа от них

**Полезное:** нет ни людей, ни направлений. Внутри свои вкладки (лента,
рефлексия, принципы, команда, график, новое), фильтры поверх них лишние
В рефлексии период стоит над вкладками, потому что она идёт по спринтам


## Почему пересобираем, а не чиним

Код: один файл `index.html` на 728 КБ, 6107 правил CSS, 2881 `!important`.
Правка в одном месте ломает другое, потому что специфичность выиграна силой, а не структурой

Данные: 503 записи назывались клиентами, по факту оплаты их около 30. Три разных числа
клиентов за один день, потому что определение каждый раз выводилось заново

Главная боль дословно: «у меня голова ломается от этой системы»

## Главное правило, из которого следует всё остальное

**У каждого поля должно быть понятно, кто и когда его заполняет**

Путей три:

```
система сама          считается из данных, человек не трогает
человек в момент      вводит тогда, когда и так делает это действие
человек через Клода   надиктовал или скинул, Клод разложил по полям
```

Поля, на которые нет ответа «кто и когда», не заводим

Участник может заполнять данные через авторизованного AI-помощника. Ответственность за полноту и подтверждение результата остаётся у участника. Для каждого поля должен быть определён источник и момент заполнения.

Новые поля добавляются только при определённом источнике, владельце и проверяемой пользе. Неподтверждённые или отсутствующие данные не подменяются нулём.

Отсюда второе правило: **за каждый ручной ввод система отдаёт что-то видимое сразу**.
Закрыл задачу по человеку, увидел, как он ушёл из списка «без активных задач»
Поставил стадию «не сейчас», увидел созданную задачу
