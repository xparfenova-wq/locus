# ЧАСТЬ III-А. АДРЕСА СТРАНИЦ

## Правило

**Любое состояние, которое можно показать, имеет адрес.** Открыл карточку,
адрес в строке поменялся. Скопировал, отправил, человек попал туда же В первой версии Локуса ссылки были не у всего, и каждый раз приходилось
объяснять словами, куда зайти. Это закрывается здесь

## Схема

Короткий номер, а не название: название меняется, ссылка ломается

```
/synapt/4827             задача 4827, направление первым
/synapt/4827#p12         подзадача
/ljudi/212               человек
/proekty/48              проект
/rassylki/7              рассылка
/okr/15                  цель
/synapt                  направление
/synapt/zadachi          задачи направления
/synapt/kontent          контент-план
/synapt/strategija       стратегия направления
/planerka/media?nedelja=43   планёрка Медиа, неделя 43
/okr?period=2026-q4      ОКР на квартал
/moe                     моё пространство
/kabinet                 личный кабинет
/poleznoe/lenta          вкладка Полезного
/poisk                   поиск по всему Локусу, отдельная страница
/poisk?chto=клиент А      поиск с готовым запросом
/poisk?chto=клиент А&tip=zadacha   поиск, отобранный по типу
/ljudi?rassylka=2        Люди, отобранные по рассылке
/ljudi?rassylka=2&status_rassylki=otvetil   плюс статус в рассылке
/ljudi?stadija=v_rabote  Люди, отобранные по стадии
```

**Поиск это отдельная страница, а не только слой поверх экрана.**
Палитра по Cmd+K при этом остаётся: она для тех, кто
знает, что ищет, страница – чтобы смотреть выдачу целиком,
группами по типам, с отбором и ссылкой на конкретный результат

**Направление идёт первым в адресе задачи.** Так по ссылке видно, к чему
она относится, не открывая

Задача сменила направление: адрес стал новым, а старая ссылка отвечает
перенаправлением на него, а не ошибкой. Номер задачи уникален во всём
Локусе, направление в адресе это подсказка человеку, а не часть ключа

## Что ещё получает адрес

```
фильтры в списке       /zadachi?napravlenie=media&status=v_processe
открытая подзадача     /synapt/4827#p12, она же полноценная задача
комментарий            /synapt/4827#k-77, прокрутка к нити
секция истории         /ljudi/212#istorija
```

## Кнопка «скопировать ссылку»

**Не на каждом состоянии, а на каждой карточке и экране**

```
есть кнопка      карточка задачи, человека, проекта, цели
                 экран направления, планёрки, контент-плана
                 страница Полезного

нет кнопки       попапы подтверждения, тосты, подсказки
                 открытый фильтр, раскрытый аккордеон
```

Правило: кнопка там, где человеку есть что показать другому. Адрес при этом
меняется всегда, даже там, где кнопки нет, чтобы можно было скопировать
из адресной строки

Один клик, ссылка в буфере, тост «Ссылка скопирована»

Без кнопки люди копируют из адресной строки, а на телефоне это неудобно

## Заголовок вкладки браузера

Название сущности первым, Локус вторым: «Отрисовать баннеры, Локус»
Иначе десяток открытых вкладок выглядит одинаково
