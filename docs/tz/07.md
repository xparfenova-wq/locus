# ЧАСТЬ IV. ПОИСК

Поиск обязателен, не улучшение. Это главное лекарство от «голова ломается»:
при 1518 людях навигация по разделам требует держать структуру в голове,
поиск заменяет её на память об имени

## Как открывается и закрывается

```
Cmd+K           с клавиатуры, в любом месте
/               тоже открывает, если курсор не в поле ввода
иконка в шапке  мышкой
Esc             закрывает
```

Открывается слоем поверх экрана, по центру, ширина 560px. Фон за ним затемняется
Фокус сразу в поле, печатать можно немедленно

## Что ищет

```
люди        по имени, телефону, почте, домену, названию компании
задачи      по названию и описанию
проекты     по названию
файлы       по имени файла
страницы    по заголовку и тексту
направления по названию
```

## Как показывает

Результаты сгруппированы по типу, **до пяти на группу**. Группы в порядке:
люди, задачи, проекты, файлы, страницы

```
ЛЮДИ
  Светлана клиент А          Медиа, клиент
  Наталья Астапкович        Synapt, лид

ЗАДАЧИ
  Отправить КП Газизову     Synapt, в процессе
  Согласовать ролики        Медиа, в плане

ПРОЕКТЫ
  Стратегия бренда            клиент А, Медиа
```

У каждой строки подпись с контекстом: направление и статус. Иначе из десяти
«Кать» не понять, какая нужна

Совпадение подсвечено в тексте

## Что делает выбор

Нажал на строку, открылся нужный экран: карточка человека, карточка задачи,
страница проекта

Стрелками вверх и вниз ходим по списку, Enter открывает

## Если ничего не нашлось

Текст «Ничего не нашлось по запросу Хантико» и кнопка «искать в архиве»,
потому что чаще всего искомое именно там

## Быстрый ввод одной строкой

В том же окне поиска: если строка похожа на задачу, под результатами появляется
предложение «создать задачу»

```
КП Газизову до пятницы редактор А
  ↓
создать задачу: КП Газизову, 24 октября, редактор А, Synapt
```

Разбирается на сервере, чтобы один код работал и в поиске, и в боте
До создания видно, что система поняла, и это можно поправить

## Технически

FTS5 в SQLite по всем таблицам, один запрос к серверу, не пять. Результат
приходит за один раз
