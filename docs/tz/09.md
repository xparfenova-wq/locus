# ЧАСТЬ V-А. КОГДА ЧТО-ТО СЛОМАЛОСЬ

## Что уже работает

Сторож `locus-watch.sh` стоит на сервере и проверяет каждые пять минут:

```
находится ли адрес в интернете     проверка DNS
открывается ли страница            код ответа 200
жива ли служба                     systemctl is-active
```

Нашёл проблему, пишет администратору в Telegram один раз, а не каждые пять минут
Служба перезапускается сама при падении (`Restart=always`)

Снимок базы делается каждые 10 минут, ночной бэкап в 3 часа

## Что добавляем

### Проверка не только страницы, но и данных

Сейчас сторож видит, что страница открылась. Этого мало: страница может
открыться, а данные не отдаться

```
добавляем     запрос к API за числом задач текущей недели
              если ответ не число или ошибка, это поломка
```

### Автопочинка в три шага

```
1. служба упала          перезапуск, уже работает
2. служба жива, API мёртв  перезапуск службы, один раз
3. не помогло              откат на последний снимок базы
                           и сообщение администратору: «откатил на снимок 14:30»
```

Третий шаг делается только с подтверждением: сторож пишет
«база не отвечает, откатить на снимок 14:30?» и ждёт ответа в боте

**Почему не автоматом:** откат теряет работу с момента снимка
Это решение человека

### Техническая диагностика

Блок «Платформа» в личном кабинете отменён администратором в позднем разборе интерфейса
28 октября. Не возвращать его по раннему описанию. Пять фактов остаются
доступны технической диагностике через защищённый GET /api/sostojanie:

```
служба            работает, запущена 3 дня назад
последний снимок  10 минут назад
ночной бэкап      сегодня 03:00, проверен восстановлением
место на диске    4 ГБ свободно
ошибки за сутки   0
```
