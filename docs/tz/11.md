# ЧАСТЬ V-В. ПРОИЗВОДИТЕЛЬНОСТЬ

На прототипе всё быстро, потому что данных нет. Чтобы через год
не затормозило, закладываем сразу

**Индексы** на поля, по которым идёт поиск и фильтрация:

```
zadachi            sprint, otvetstvennyj, napravlenie, status, roditel_id
sotrudnichestva    chelovek_id, napravlenie, rol
zhurnal            obekt, obekt_id, kogda
rassylka_ljudi     rassylka_id, chelovek_id, status
kontakty           znachenie_norm
```

**Постраничная выдача** в списках людей и задач: 50 строк и кнопка «ещё»

**Один запрос вместо цикла.** Список задач с именами исполнителей берётся
одним запросом с соединением таблиц, а не запросом на каждую строку

**Архивирование не делаем.** При десяти людях за год накопится около
5000 задач и 10 000 записей журнала. Для SQLite это мало
