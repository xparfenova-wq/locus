# ЧАСТЬ VIII. ВРЕМЯ И ПЕРИОДЫ

Все даты в базе в UTC в формате ISO-8601

Отображение по московскому времени

Неделя по ISO-8601, с понедельника

**Номер недели не подменяет дату.** В поле даты лежит дата, в поле недели
номер недели, и одно не кладётся на место другого. Причина: 17 октября
уже был сбой этого рода, в поле даты стоял номер недели, и снимки
потерялись

Где неделя хранится полем, а где считается:

```
хранится    snimki_planerki.nedelja, rassylka_plan.nedelja,
            grafik.nedelja: снимок и план привязаны к конкретной
            неделе, иначе их не найти
считается   у задачи поле sprint это и есть номер недели,
            отдельно он не дублируется
```
