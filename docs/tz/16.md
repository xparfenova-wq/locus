# ЧАСТЬ VIII-А. AI ВНУТРИ ЛОКУСА

AI-функции рассматриваются отдельно от детерминированных расчётов и не подменяют проверяемые факты.

## Что делать НЕ надо

**Не надо делать AI-аналитика, который сам смотрит на данные
и формулирует выводы.** Причина простая: он будет убедительно
ошибаться, и это хуже, чем молчание

```
система правил     «цель отстаёт на 18 процентов» → всегда правда
AI-аналитик        «Медиа буксует из-за перегруза участницы Е» → звучит умно,
                   может быть полной выдумкой
```

На десяти людях и сотне задач данных слишком мало, чтобы отличить
закономерность от совпадения. AI увидит закономерность всё равно,
потому что он так устроен

## Что делать надо

**Разделить на два слоя, и это ключ ко всему:**

```
СЛОЙ 1, правила      Инсайты Локуса, считаются формулой
                     всегда правда, можно проверить руками
                     работает без интернета и без денег за токены

СЛОЙ 2, разговор     диалоговое окно, где человек спрашивает
                     отвечает Клод, читая данные через API
                     ответ помечен как мнение, а не как факт
```

Первый слой это система. Второй это инструмент

## Как устроен слой разговора

**Вход:** кнопка в правом нижнем углу на любом экране, открывает панель

**Что видит Клод:** только то, что видит человек. Если у человека закрыты
деньги, Клод про деньги не отвечает

**Контекст передаётся автоматически:**

```
на экране задачи       эта задача, её подзадачи, история
на экране человека     карточка, сотрудничества, история
в планёрке             вся сводка направления за неделю
в ОКР                  цели периода с фактами и замерами
```

**Примеры вопросов, на которые это реально работает:**

```
«Что изменилось по Synapt за две недели»
«Почему цель по контактам отстаёт»
«Разнеси эту расшифровку зума по задачам»
«Сформулируй фоллоуап по планёрке»
«Кого мы давно не трогали в Медиа»
```

Первые два это чтение и сведение. Третий это запись через API.
Четвёртый и пятый это пересказ данных

**Каждый ответ подписан:**

```
Ответ собран по данным Локуса на 19 октября, 14:30
Это мнение модели, проверь числа в разделах
```

## Чего в этом слое не будет

```
нет автоматических выводов без запроса человека
нет «AI заметил, что...» в уведомлениях
нет оценок людей
нет записи в базу без подтверждения человеком
```

Последнее важно: Клод предлагает список задач, человек правит и подтверждает
Запись идёт пакетом через API с защитой от повторов, как сейчас

## Приоритет реализации

Начинать надо со слоя правил, он даёт 80 процентов пользы за 20 процентов
работы. Слой разговора добавить после запуска, когда в базе появятся
настоящие данные

Авторизованные внешние помощники могут работать через API. Встроенный диалог относится к следующей очереди и не является условием готовности основных рабочих цепочек.
