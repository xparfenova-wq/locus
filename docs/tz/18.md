# ЧАСТЬ X. ПРАВИЛА РАБОТЫ С КОДОМ

**Ни одного цвета, радиуса и кегля вне слоя токенов**

**Слои каскада вместо `!important`.** При объявленном порядке слоёв `!important`
структурно не нужен

**Линтер проверяет и CSS, и HTML.** Семь запретов из девяти живут в HTML, а не в CSS.
HTML гоняется через существующий `scripts_agents/style-lint.py`, CSS через свой линтер

Линтер ловит обходные пути:
```
select без appearance
appearance: menulist, textfield, button
шорткат font (протаскивает вес и кегль)
border-left-width вместе с border-left-color
transform: translate(0,-2px) и свойство translate
!important
```

**Файл на раздел, не один файл на всё.** Причина старого долга: 728 КБ в одном файле

**Запрещено:** антиква, курсив, длинное тире, точки в конце заголовков, кругляшок-разделитель,
полоска слева, тени на карточках, подъём при наведении, вложенные подложки, серые панели
вокруг групп, системный выпадающий список, кегль мельче 11.5px

**Эмодзи не запрещены в интерфейсе**, но метка направления это точка
цветом, не эмодзи: в списке из 136 строк эмодзи шумят и ломают высоту ряда
Где эмодзи уместны, решаем глазами на прототипе
