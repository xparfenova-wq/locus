# ЧАСТЬ XI. МЕТРИКА УСПЕХА ПЕРЕСБОРКИ

Своё же правило: нет замера, нет результата. Три числа, замерить до старта и смотреть
каждую неделю:

```
1  сколько клиентов и лидов имеют следующий шаг     отвечает за «база не ради базы»
2  сколько касаний записано за неделю               отвечает за главное допущение
3  сколько человек из десяти открывали Локус в будний день   отвечает за то, что система жива
```
