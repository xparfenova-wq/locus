# ЧАСТЬ XII. УСЛОВИЯ ОКОНЧАТЕЛЬНОЙ ПРИЁМКИ

1. Все обязательные сценарии подтверждены на сервере, в базе и на экране; одна открывшаяся страница не считается приёмкой функции
2. Общие настройки, уведомления и реальные внешние подключения проходят отдельную предметную проверку
3. Перенос включает сверку исходных строк, связей и оригинальных файлов; неоднозначные бизнес-решения подтверждает владелец данных
4. Восстановление проверяется на отдельной машине, включая конфигурацию, службы, доступы и файлы
5. Итоговая проверка охватывает роли, конкурентную работу, обрыв сети, повтор, отмену, телефон, планшет и компьютер

Актуальный статус реализации и известные пробелы приведены в СТАТУС-РЕВЬЮ.md. Условия готовности не считаются выполненными по наличию этого документа.
