Существующий POST /api/arhiv и обычные PATCH сохраняют совместимость. Новый подтверждённый POST /api/arhiv принимает tablica,id,arhiv,versija,kontekst,zapros_kljuch. GET /api/arhiv/predprosmotr?tablica=...&id=... читает контекст; GET /api/arhiv/proverka?tablica=...&id=...&zapros_kljuch=... возвращает собственный исход; POST /api/arhiv/otmena_popytki резервирует отменённый ключ; POST /api/arhiv/otmenit отменяет сохранённое действие целиком по ishodnyj_kljuch. Повтор с тем же ключом не делает новый переход. Конфликт источников/архивных полей/родителя/направления не заменяет чужие изменения. Независимая правка поля сохраняется. Неизвестная доставка проверяется до повтора, перезагрузка сама не пишет. Квитанции147 добавляются пустыми, прежние данные и даты не переписываются
