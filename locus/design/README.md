# Единый интерфейс Locus

Снимки планёрок: `weekly-snapshots.md`. Подпись источника сообщает фактическое время сохранения или реконструкцию; прошлый снимок доступен для чтения. Старые дополнительные сведения не подменяются свежими. Сравнение показывает годы и источники обеих недель, при загрузке убирает прежние значения и игнорирует поздний ответ. При отзыве доступа к деньгам прежнее сравнение закрывается

Счётчик непрочитанных уведомлений находится внутри границ кнопки верхнего меню. На ширине 768/1024 он не выступает за экран и не создаёт боковую прокрутку; проверка использует непустую очередь уведомлений, включая «9+»

Недельные срезы целей: `weekly-goals.md`. Четыре календарных представления используют общие токены; на телефоне две колонки. Переход сохраняет исходную цель и выбранное окно. Быстрый замер открывает общую форму, передаёт исходную десятичную строку и сохраняет ввод при отказе. Исходная база без замеров подписана явно. Старые снимки не дополняются текущими числами

Источник точных значений: `design/system.json`. Сборка: `python3 ops/design_system.py --write`. Проверка: `python3 ops/design_system.py`.

Живые компоненты: `/ui-system.html`; прежний брендбук `/brendbuk.html` сохраняется. Новый каталог пока не&nbsp;означает приёмку всех рабочих окон

Новые компоненты используют токены и&nbsp;общий CSS. Нельзя копировать стили соседней формы в&nbsp;ещё одну страницу, придумывать новый оттенок/радиус/кегль или&nbsp;скрывать новое отклонение обновлением baseline. Исключение должно иметь отдельную именованную роль, объяснение и&nbsp;место проверки в&nbsp;каноне

Порядок изменения: правило → токен/общий компонент → все места использования → проверка состояний и&nbsp;экранов. Компьютер/планшет/телефон:320,390,768,1024,1440px и&nbsp;промежуточные ширины. Дополнительно длинный текст,200%увеличение, клавиатура, safe-area, ошибка чтения, конфликт, неизвестная запись, возврат фокуса и&nbsp;повторное открытие

Проверяются не&nbsp;только отсутствие прокрутки страницы, но&nbsp;и&nbsp;реальные границы кнопок/крестика/выпадающего списка. Кнопка не&nbsp;должна оказаться за&nbsp;скрытым overflow. Область мобильного нажатия от&nbsp;44×44px, ввод от&nbsp;16px. Неподтверждённая запись предлагает проверку; ошибка чтения не&nbsp;выглядит пустым списком

Тесты и&nbsp;образцы не&nbsp;создают рабочие записи и&nbsp;уведомления. `ui-specimen-boundary.js` блокирует API в&nbsp;образцах. Визуальная приёмка конкретного рабочего окна ведётся отдельно от&nbsp;приёмки общей оболочки

Автоматическая проверка: `npm run test:design`. Проверяет совпадение собранных токенов, новые буквальные значения и&nbsp;неизвестные переменные. Старые 5450 деклараций зафиксированы из&nbsp;неизменяемогоabea975 для&nbsp;постепенного сокращения; они не&nbsp;объявлены соответствующими канону. Динамическая геометрия и&nbsp;реальные вычисленные стили проверяются браузером отдельно

Реестр окон и&nbsp;выборщиков строится из&nbsp;текущих исходников: `python3 ops/design_inventory.py --write`. Проверка включена в&nbsp;test:design и&nbsp;не&nbsp;даёт оставить старый реестр после добавления формы. Учитываются select, редактируемые подсказки datalist, раскрываемые блоки details и&nbsp;общие фильтры. В&nbsp;реестре хеши исходных файлов; запись pending означает, что&nbsp;все варианты конкретного места ещё не&nbsp;приняты. Нативные сценарии редактора целей проверяются отдельно

Редактируемые подсказки используют `public/js/suggestions.js` и&nbsp;общую поверхность списка. Системный datalist сохраняет справочник вариантов, но&nbsp;родное меню браузера отключено. Ввод остаётся свободным: наведение ничего не&nbsp;выбирает, текст фильтрует варианты, стрелки и&nbsp;Enter выбирают подсказку. Изменение справочника обновляет открытый список. Выбор выдаёт по&nbsp;одному input/change; Escape оставляет введённый текст

Формы средней сложности используют роль modal-width-form620px на&nbsp;компьютере; телефон остаётся штатным нижним листом. Редактор целей использует общие поля, подписи, кнопки, счётчик, сравнение и&nbsp;проверку сохранения

Заголовок общего окна переносится целиком, включая длинное слово. На&nbsp;телефоне резерв под&nbsp;кнопки рассчитывается из&nbsp;общих токенов: 64px для&nbsp;одной, 120px для&nbsp;двух. Высота шапки не&nbsp;меньше 68px. Появление или&nbsp;скрытие подтверждения автоматически меняет резерв; текст не&nbsp;заходит под&nbsp;действия

Уточнение 20 ноября: раскрывающиеся списки открываются наведением, остальные способы управления сохраняются. Видимое поле файла, календарь, галочки, радио и&nbsp;прогресс используют общие компоненты. Стандартные формы на&nbsp;телефоне идут одной колонкой. Наведение не&nbsp;меняет значения и&nbsp;не&nbsp;сохраняет данные. Нижняя шторка календаря остаётся открытой до&nbsp;выбора или&nbsp;закрытия; изменение высоты встроенного образца сохраняет панель

После выбора даты календарь не&nbsp;открывается повторно под&nbsp;неподвижным курсором. Новый календарь или&nbsp;общий список, появившийся после перерисовки формы, ждёт нового движения мыши для&nbsp;наведения. Явный клик и&nbsp;клавиатура открывают его&nbsp;сразу

Поле замера передаёт десятичный текст серверному валидатору до&nbsp;преобразования в&nbsp;число. Слишком точная дробь и&nbsp;underflow отклоняются без&nbsp;округления и&nbsp;без&nbsp;новой строки истории. Ошибки числа, даты и&nbsp;источника показаны рядом с&nbsp;полем через `l-field-error`, подпись через `l-field-hint`. Значения остаются в&nbsp;форме. Подтверждённый отказ разрешает исправить ввод; неизвестный ответ сохраняет прежний сценарий проверки квитанции

Разбиение по&nbsp;кварталам использует общие поля и&nbsp;ошибку вне скрываемой строки кнопки. На&nbsp;телефоне кварталы идут двумя колонками, ввод16px. Пустое поле требует явного числа, включая0; исходный десятичный текст доходит до&nbsp;серверной проверки точности. Название результата выводится как&nbsp;текст

Временной срез сохраняет номер цели и&nbsp;её&nbsp;собственный период. Факт выбранного окна подписан датой и&nbsp;источником; общий факт и&nbsp;план цели остаются рядом. План на&nbsp;другой период не&nbsp;угадывается. Ошибка чтения сохраняет подписанный предыдущий срез и&nbsp;предлагает повтор; отказ доступа скрывает прежние данные. Положение карточки и&nbsp;сообщения учитывает фактическую высоту закреплённого меню и&nbsp;отступ space-3, включая изменение высоты при&nbsp;загрузке. Ручная прокрутка прекращает удержание позиции

Стрелки меняют окно выбранной цели. Кнопка «Все цели периода» отдельно открывает общий список; кнопка «К периоду цели» возвращает её&nbsp;исходный план и&nbsp;редактирование


Периодные планы одной цели используют общую форму, поля и кнопки: год → кварталы, квартал → месяцы. Поле принимает исходную десятичную строку; пустое значение не становится нулём, ноль сохраняется явно. Расхождение показывается без блокировки. План, факт на дату и движение за период различаются; без начального наблюдения движение неизвестно. Черновик и квитанция разделены по участнику, вкладке, цели и периоду. После потерянного ответа сначала предлагается проверка, повтор — явный. Конфликт сохраняется после перезагрузки, сравнение показывает актуальные планы. Отзыв доступа скрывает старые числа. Основные состояния проверяются на 1440/390/320


При выбранной цели позиция среза учитывает позднее восстановление прокрутки браузером. Наблюдаются scroll/pageshow/resize и реальная нижняя граница меню; движение меньше половины пикселя не вызывает нового скролла. Ручной wheel/touchstart/pointerdown/keydown прекращает удержание. Повторные переходы после формы и ручная прокрутка проверяются отдельно от первого открытия


ОКР: удалённые записи загружаются асинхронно в блоке перед контекстом среза. Исчезновение пустой истории меняет положение контекста без изменения меню и без события scroll. Общий ResizeObserver отслеживает также родительскую колонку контекста. Проверка задерживает GET истории удалений: на прежнем коде стабильно воспроизводится перекрытие, на новом проходят все 9 случаев с поздним сдвигом и ручной прокруткой


Высота мобильной карусели ОКР обновляется в requestAnimationFrame и только при изменении значения. ResizeObserver не пишет высоту предка наблюдаемой карточки во время своей доставки: это вызывало ResizeObserver loop и ложные автоматические отчёты. Проверка исторических срезов до исправления давала6служебных отчётов, после исправления —0, с теми же фактами и переходами на1440/390/320
