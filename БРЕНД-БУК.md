# Интерфейс Локуса: канон и&nbsp;проверка

Редакция 20 ноября 2026. Полная визуальная приёмка всех рабочих окон продолжается. Первые семейства компонентов и&nbsp;общие контролы проверяются отдельно; статус каждого места использования хранится в&nbsp;реестре

Точные значения задаёт `locus/design/system.json`. Общие компоненты используют собранный `locus/public/css/design-tokens.css`. Этот документ объясняет правила и&nbsp;границы проверки. Живой каталог: `/ui-system.html`; карта продукта: `/readiness.html`

Предыдущая редакция сохранена в `proverka/design-system-2026-11-20/Брендбук – до&nbsp;уточнения общих контролов.md`. Её&nbsp;прежние количественные оценки не&nbsp;заменяют текущую проверку

## Принципы

1. Один компонент на&nbsp;одну роль; новые размеры не&nbsp;добавляются в&nbsp;отдельной странице
2. Компактность сохраняет читаемость, фокус и&nbsp;область нажатия
3. Цвет объясняет состояние; общий каркас и&nbsp;навигация остаются монохромными
4. Неизвестный исход, ошибка чтения и&nbsp;пустой список выглядят по-разному
5. Ни&nbsp;одна форма не&nbsp;теряет текст при ошибке, закрытии или&nbsp;смене размера экрана
6. Выпадающие списки открываются при настоящем наведении; касание и&nbsp;клавиатура сохраняют полный доступ
7. Наведение ничего не&nbsp;выбирает, не&nbsp;отправляет и&nbsp;не&nbsp;сохраняет
8. Календарь и&nbsp;видимое поле выбора файла используют фирменные компоненты Локуса

## Поведение раскрытия

На&nbsp;компьютере списки выбора, меню и&nbsp;раскрываемые блоки открываются при настоящем наведении. Задержки открытия 90ms и&nbsp;ухода 120ms берутся из&nbsp;общих токенов. Переход курсора через зазор к&nbsp;панели сохраняет её&nbsp;открытой. Клик после наведения сохраняет открытый выбор. Выбор значения и&nbsp;действие требуют явного подтверждения пользователя

Наведение сохраняет текущее поле ввода в&nbsp;фокусе и&nbsp;не&nbsp;отправляет события изменения. При работе клавиатурой открытый список сохраняется до&nbsp;выбора, Escape, Tab или&nbsp;явного перехода. Стрелки, Enter и&nbsp;Space работают с&nbsp;настоящими полями; значение остаётся в&nbsp;исходном select

На&nbsp;сенсорном устройстве выбор открывается касанием. Нижняя шторка календаря остаётся открытой до&nbsp;выбора даты или&nbsp;закрытия: её&nbsp;фон перекрывает исходное поле и&nbsp;не&nbsp;должен вызывать повторное закрытие и&nbsp;открытие

Раскрываемый блок details можно открыть наведением, закрепить кликом и&nbsp;закрыть Escape. Фокус внутри блока сохраняет раскрытое содержимое. Стрелка использует общий шеврон. Информационная круглая кнопка сохраняет свой отдельный вид

## Поля и&nbsp;подписи

Стандартная форма использует две колонки на&nbsp;широком экране и&nbsp;одну на&nbsp;узком. Широкое поле занимает весь ряд. Подпись стоит над значением, ошибка под соответствующим полем. Новое обычное поле: высота от&nbsp;38px на&nbsp;компьютере, от&nbsp;44px на&nbsp;телефоне; кегль 13/16px, радиус 10px, внутренние отступы 9×15px. Названные исключения вроде компактного выбора в&nbsp;фильтре имеют отдельную роль

Состояния отличаются явно: обычное, фокус, заполнено, ошибка, недоступно, только просмотр, сохранение, неизвестный исход, конфликт. Ошибка чтения сохраняет уже введённое и&nbsp;предлагает повтор чтения. Неизвестный исход предлагает проверку собственной операции. Внешний вид ошибки не&nbsp;заменяет серверную проверку

## Редактируемые подсказки

Поле рубрики и&nbsp;поиск человека используют общий компонент `public/js/suggestions.js`. Нативное меню datalist отключено, сам справочник вариантов сохраняется. Список раскрывается наведением и&nbsp;нажатием, ввод фильтрует варианты. Можно выбрать подсказку стрелками и&nbsp;Enter или&nbsp;оставить свой текст. Escape закрывает список без&nbsp;замены текста. Наведение не&nbsp;забирает фокус другого поля и&nbsp;не&nbsp;вызывает input/change; явный выбор выдаёт по&nbsp;одному событию. Новые варианты справочника обновляют открытый список

## Календарь

Календарь рисует `public/js/kalendar.js`, оформление задаёт `public/css/date-picker.css`. Родной системный календарь скрыт. Значение и&nbsp;исходные input/change остаются на&nbsp;настоящем поле даты, поэтому формы используют прежний проверенный путь сохранения

Неделя начинается с&nbsp;понедельника. Сегодня, выбранная дата и&nbsp;фокус клавиатуры имеют отдельные признаки. Панель поддерживает min/max, обязательность, недоступность и&nbsp;просмотр. Обязательную дату нельзя очистить; недоступный день не&nbsp;выбирается. Повторный выбор той же&nbsp;даты не&nbsp;создаёт новое изменение

Выбор отправляет по&nbsp;одному input и&nbsp;change. Простое открытие, наведение, уход курсора и&nbsp;изменение размеров экрана дату не&nbsp;сохраняют. Панель помещается в&nbsp;доступный экран, сохраняется при изменении высоты образца и&nbsp;закрывается вместе с&nbsp;удалённым полем

Стрелки меняют день, Home/End переходят к&nbsp;границе недели, PageUp/PageDown листают месяц, Shift с&nbsp;ними меняет год. Enter подтверждает, Escape закрывает. На&nbsp;телефоне дни и&nbsp;действия имеют высоту 44px; при ширине 320px сетка сохраняет ширину нажатия 44px

После выбора даты и&nbsp;перерисовки формы неподвижный курсор не&nbsp;вызывает повторного раскрытия. Новое движение мыши возобновляет наведение; явное нажатие и&nbsp;клавиатура доступны сразу

## Выбор файла

Видимое поле получает фирменную кнопку и&nbsp;подпись с&nbsp;именем выбранного файла. Кнопка использует обычный шрифт, капсулу, общую рамку, фокус и&nbsp;доступность; имя переносится и&nbsp;выводится как&nbsp;текст. Несколько файлов, disabled, fieldset и&nbsp;сброс формы сохраняют свою семантику

Исходный input остаётся на&nbsp;месте со&nbsp;своими accept, multiple, required, идентификатором и&nbsp;обработчиками. Скрытые входы готовых загрузчиков сохраняют существующие кнопки. Сам диалог выбора файла открывается явным нажатием. В&nbsp;образцах файл остаётся в&nbsp;браузере

## Галочки, выбор варианта, прогресс

Галочка и&nbsp;радио сохраняют настоящие checkbox/radio и&nbsp;получают общие роли `.l-checkbox` и `.l-radio`. Размер 20px; квадратный микрорадиус 2px и&nbsp;круглая форма различаются по&nbsp;назначению. Отмеченное, частичное, фокус, ошибка и&nbsp;недоступное состояние оформлены явно. Space и&nbsp;стрелки продолжают работать как&nbsp;у&nbsp;настоящих полей

Индикатор прогресса использует общую линию и&nbsp;основной цвет, сохраняя значение и&nbsp;доступное описание. У&nbsp;ползунка настроек общий стиль; существующие компактный ползунок палитры и&nbsp;ползунок ресурса сохраняют свои отдельные роли до&nbsp;предметной сверки. Полный список состояний не&nbsp;означает автоматической приёмки всех мест использования

## Окна и&nbsp;связанные формы

Окна используют общую оболочку O.modalka. Крестик, возврат фокуса, Escape, длинное содержимое и&nbsp;вложенное окно проверяются как&nbsp;часть сценария. Средняя форма имеет роль ширины 620px на&nbsp;компьютере, на&nbsp;телефоне становится штатным нижним листом. Отступы, поля и&nbsp;ошибки берутся из&nbsp;общих ролей

Редактор цели использует общие поля, объясняет доступность, сохраняет черновик и&nbsp;предлагает сравнение одновременных правок. Сохранение, неизвестный ответ и&nbsp;ошибка локальной очистки различаются. Кнопка удаления, архив и&nbsp;возврат учитывают серверные права и&nbsp;связи

## Проверка и&nbsp;изменения

Выбор временного окна сохраняет номер цели и&nbsp;её&nbsp;собственный период. В&nbsp;строке результата показаны факт окна с&nbsp;датой и&nbsp;источником и&nbsp;общий факт с&nbsp;планом цели. Если план этого окна отдельно не&nbsp;задан, его&nbsp;не&nbsp;подставляют из&nbsp;годового. Ошибка чтения оставляет подписанный предыдущий срез и&nbsp;даёт повтор; отказ доступа скрывает прежние сведения. Карточка и&nbsp;сообщение начинаются ниже фактической высоты закреплённого меню плюс space-3. Изменение высоты меню при&nbsp;загрузке учитывается; ручная прокрутка прекращает удержание позиции

Форма разбиения по&nbsp;кварталам использует общие поля: четыре колонки на&nbsp;компьютере, две на&nbsp;телефоне. Ошибка видна под&nbsp;планами и&nbsp;остаётся доступной после переноса кнопки в&nbsp;шапку. Пустое поле не&nbsp;заменяется нулём;0 вводится явно. Десятичный текст сохраняется до&nbsp;серверной проверки точности

Заголовок общего окна переносится целиком, включая длинное слово или&nbsp;ссылку. На&nbsp;телефоне кнопки остаются в&nbsp;шапке: каждая занимает 44px, между ними 12px, до&nbsp;края 12px. Между текстом и&nbsp;кнопками остаётся 8px. Правая область заголовка резервирует 64px для&nbsp;одной кнопки или&nbsp;120px для&nbsp;двух; высота шапки не&nbsp;меньше 68px. Появление второй кнопки автоматически увеличивает резерв. Название не&nbsp;обрезается и&nbsp;не&nbsp;заходит под&nbsp;действия

Обязательные ширины:320,390,768,1024,1440px и&nbsp;промежуточные значения. Проверяются длинное содержимое, клавиатура, касание, фокус, min/max, обязательность, недоступность, ошибки, повторное открытие и&nbsp;потеря ответа. Встроенный образец проверяется и&nbsp;внутри каталога, и&nbsp;отдельно

Проверки сборки: `python3 ops/design_system.py`, `python3 ops/design_inventory.py`, `python3 ops/design_guard.py`, `npm run test:design`. После изменения исходников реестр пересобирается явно с `--write`. Старый baseline нельзя обновлять ради сокрытия нового отклонения

Текущий реестр содержит 157 мест открытия окон и&nbsp;125 мест выбора и&nbsp;раскрытия. Статус pending сохраняется, пока не&nbsp;приняты все реальные варианты конкретного места. Прежние 5450 деклараций сохранены для&nbsp;постепенной миграции; они не&nbsp;являются 5450 дефектами и&nbsp;не&nbsp;объявлены соответствующими канону

Изменение проходит путь: правило → токен или&nbsp;общий компонент → реальные места использования → состояния и&nbsp;экраны → функциональная проверка → проверенная установка. Общая готовность Локуса учитывает и&nbsp;поведение, и&nbsp;сохранность данных, и&nbsp;интерфейс


Периодное планирование: год разбивается на кварталы, квартал на месяцы в одной форме общего канона. Два поля в строке на телефоне, ввод 16px, действия с общими высотой и интервалом space-2. Неизвестное движение и незаданный план показываются отдельно от нуля. Сравнение параллельных правок содержит сохранённые значения, а введённые остаются в полях. Неподтверждённое сохранение не повторяется автоматически. Последнее сохранение можно отменить целиком, в том числе после перезагрузки; более поздние правки защищены


## 21.11.2026 — подтверждение пересчёта недели

Ручной пересчёт прошлой недели открывает общую модальную карточку. Две версии расположены рядом на широком экране и последовательно на телефоне. Подписи «Сохранено» и «После пересчёта», дата снимка и год недели обязательны. Неизвестное значение обозначается тире, скрытое — словом «скрыто»; пропуск старого блока не превращается в ноль. Все разделы доступны для сравнения. Заголовки, кнопки, поля, расстояния и цвета берутся из действующих токенов. Новые собственные оттенки и размеры текста не вводятся

История открывается той же карточкой: автор, время, характер изменения и просмотр прежней/новой версии. Пока неизвестен исход сохранения, вместо повторного пересчёта показана проверка попытки с отдельными действиями повторить или отменить. Сохранённая проверка содержит только ключи, область и отпечаток контекста, без деловых показателей. Отмена сохранения целостная и доступна после подтверждения результата. При потере прав показанные версии очищаются


## 21.11.2026 — архив человека и сотрудничества, подготовка

У карточки человека есть отдельное текстовое действие архива/возврата, у каждого сотрудничества своё действие с названием направления. Используются существующие кнопки fil-b и общая модальная карточка. Подтверждение объясняет область изменения; финансовые поля и документы не дублируются. Ошибки и проверка неизвестного исхода оформлены общей подписью со статусом и отдельными действиями. Хранение намерения до отправки, явный повтор и отмена соответствуют форме пересчёта недели. Человек и сотрудничество различаются и на мобильном экране. Историческая планёрка имеет подпись «Период закрыт»; имя и фотография берутся из сохранённой версии. В сравнении «За неделю» означает движение, а абсолютное значение другого окна подписывается как состояние

## 21.11.2026 — контекстная подсказка раздела

Контекстная подсказка — компактная поверхность под шапкой, без модального окна, тени и автоматического перевода фокуса. Использует существующие токены: text-body/text-meta, line-body, t1/t2, lin, kart, radius-overlay, space-2/3/4, layout-wide. Кнопка закрытия имеет область нажатия control-height-mobile (44px) на всех ширинах. Длинный текст переносится, кнопка остаётся внутри экрана. Помощь «i» доступна и после закрытия вводной подсказки. Ошибка сохранения показывается внутри той же поверхности; повтор отправки всегда явный.

## 21.11.2026 — время фокус-сессий в задаче, канон2026.11.21.2

Подтверждённый итог времени — строка метаданных в карточке, рядом компактное действие «фокус по задаче». Это текст и существующая кнопка-ссылка без дополнительной вложенной карточки. Используются text-meta/line-body/t2/space-2. Действие открывает таймер в новой вкладке и сохраняет набранный комментарий. При возврате обновляется только итог времени. На телефоне область нажатия не меньше control-height-mobile. В таймере выбранная задача показана короткой ссылкой; снять привязку можно до старта. У работающей сессии связь только для чтения. Удалённое поле «над чем работаешь» не возвращается. Та же поверхность показана в образце «Карточки».
