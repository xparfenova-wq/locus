# Тексты Локуса

Каждая подпись, кнопка, подсказка, пустое состояние и уведомление дословно.
Это не рекомендации, это текст, который попадёт в код

Тон интерфейса определяется приведёнными ниже правилами.

---

# I. ТОН

Добрый, заботливый, профессиональный. Таким администратор общается с командой

```
на ты, по имени
не командуем              «посмотри», а не «необходимо проверить»
не пугаем                 «срок прошёл», а не «ПРОСРОЧЕНО»
не льстим                 система не знает, какая работа получилась
не оцениваем              никаких «отлично», «молодец», «плохо»
пустое состояние          говорит, что делать, а не констатирует пустоту
ошибку признаём своей     «не получилось сохранить», а не «вы ввели неверно»
```

**Табу из Шкатулки, они же действуют тут:**

```
конструкция «не X, а Y»       даже когда противопоставление верное
канцелярит                     «осуществить», «данный», «в рамках»
искусственная разговорность    «упс», «ой», «давайте-ка»
длинное тире                   только короткое или запятая
точка в конце подписи          её нет
```

**Про эмодзи.** Запрета нет. В интерфейсе по умолчанию не ставим, но
в метках направлений пробуем и смотрим глазами. В сообщениях бота
допустима скобка, как администратор пишет своим

# II. КНОПКИ

Глагол в начале, без «нажмите». Одно слово, если хватает одного

```
Создать               не «Создать задачу», контекст виден
Сохранить             появляется только там, где нет автосохранения
Отменить
Удалить
Вернуть               из архива
Закрыть               закрыть задачу
Открыть
Добавить подзадачу
Добавить результат
Добавить задачу       в карточке цели
Добавить задачу       в строке проекта и человека
Выставить счёт
Пришло                отметить оплату
Скопировать ссылку
Дублировать
Сохранить как шаблон
Использовать шаблон
Перенести
Пройти онбординг
Выгрузить
```

**Пары кнопок в вопросах.** Первая делает, вторая отказывается.
Отказ формулируем словами, а не «Отмена»

```
[создать]  [не нужно]
[закрыть]  [вернуться]
[да, вернуть]  [оставить в архиве]
[вписать число]  [позже]
[перевести все]  [разобрать по одной]
[открыть её]  [всё равно создать]
```

# III. ПУСТЫЕ СОСТОЯНИЯ

Каждое говорит, что делать. Ни одно не констатирует пустоту

**Пустота это не плохая новость.** Поэтому слова «пока» и «что-то» вместо
сухого отрицания: «пока что-то тихо», а не «уведомлений нет». Человек
не должен чувствовать, что он чего-то не сделал

**Действие предлагаем глаголом «добавить»**, не «поставить»: задачу добавляют,
а не ставят над кем-то

| Где | Текст |
|---|---|
| Моё пространство, нет задач | На этой неделе задач пока нет. Добавить первую? |
| Моё пространство, нет проектов | Ты пока не ведёшь ни одного проекта. Это нормально |
| Задачи, фильтр ничего не нашёл | По этим фильтрам ничего не нашли. Сбросить? |
| Задачи направления пусты | В Медиа на этой неделе что-то пусто. Добавить задачу? |
| ОКР, нет целей | Целей на этот квартал пока нет. Добавить первую? |
| ОКР, есть цели без результатов | У цели нет результатов. По чему поймём, что дошли? |
| Планёрка, пустой блок | По клиентам на этой неделе пока тихо |
| Люди, поиск пуст | Никого не нашли. Проверь написание или заведи нового |
| Карточка человека, нет задач | По Игорю пока нет задач. Добавить следующее касание? |
| Проект, нет задач | В проекте пока пусто. Добавить задачу? |
| Проект, нет счетов | Счетов пока нет. Выставить первый? |
| Контент-план, пустой месяц | В ноябре публикаций пока нет. Добавить первую? |
| Уведомления пусты | Пока что-то тихо |
| Полезное, лента пуста | Здесь появится то, чем делится команда |
| Рефлексия, никто не написал | На этой неделе рефлексию пока не писали |
| Команда, анкета не заполнена | участница Е пока не заполнила анкету |
| Журнал пуст | Изменений пока нет |

```
  [открыть]  [изменить телефон]

  Этот Телеграм уже у Игоря Семакина. Открыть его карточку?
  [открыть]  [изменить ник]
```

```
Создать задачу «Следующее касание по Игорю»?

```


# V. ТОСТЫ

Внизу экрана, пять секунд, с кнопкой отката где можно

```
Задача закрыта.  [отменить]
Задача удалена.  [отменить]
Игорь вернулся из архива.  [отменить]
Ссылка скопирована
Сохранено
Не получилось сохранить, проверяем связь
Нет связи. Изменения не сохранятся
администратор изменила название, пока ты правил
```

Последний нужен при одновременной правке: без него человек решит,
что система потеряла его текст

# VI. УВЕДОМЛЕНИЯ

Два потока, и это главное деление. Иначе важное тонет в шуме

```
ПРО МЕНЯ          требует моего действия или касается моей работы
                  колокольчик со счётчиком, бот пишет

СОБЫТИЯ           просто происходящее вокруг моих задач
                  вкладка без счётчика, бот молчит
```

Формат один: кто, что сделал, название задачи ссылкой, контекст, когда

```
администратор поставила тебе задачу
«Отрисовать баннеры для запуска»
Automy Junior, Запуск курса, 2 часа назад

администратор перенесла срок
«Отрисовать баннеры для запуска»
было 22 октября, стало 26 октября, 10 минут назад

участница Е закрыла подзадачу
«Отрисовать баннеры для запуска»
в твоей задаче «Запуск курса», час назад

Сегодня истекает срок
«Собрать ответы на 14 вопросов»
Synapt, сегодня

администратор добавила тебя участником
«Статус-отчёт по Global Dent»
Synapt, сегодня

Тебя назначили ведущим проекта
«клиент А, ведение соцсетей»
Медиа, сегодня

Срок прошёл
«Собрать ответы на 14 вопросов»
Synapt, было 18 октября
```

«Сегодня истекает срок» приходит утром в день срока, «Срок прошёл» утром
следующего дня. Не в полночь

**Вкладка События**, без счётчика и без бота:

```
владелец написал в задаче
«Отрисовать баннеры для запуска»
Automy Junior, 5 минут назад

участница Е закрыла подзадачу
«Отрисовать баннеры»
в твоей задаче «Запуск курса», час назад

администратор изменила срок в задаче, где ты участник
«Статус-отчёт по Global Dent»
Synapt, вчера
```

**Уведомления про согласование нет.** Статус «на согласовании» означает
«вынесено на общее обсуждение», а не «висит на конкретном человеке».
Согласования идут в Telegram, Локус их не ведёт

# VII. БОТ В ТЕЛЕГРАМЕ

То же содержание, но человеческим письмом. Как администратор пишет своим

```
Привет! администратор поставила тебе задачу «Отрисовать баннеры для запуска»
по Automy Junior, срок 26 октября
Открыть: locus.oreshkin.me/z/1428

Привет! У тебя вчера вышел срок по задаче «Собрать ответы на 14 вопросов»
Открыть: locus.oreshkin.me/z/1431

Привет! участница Е закрыла подзадачу в твоей задаче «Запуск курса»
Открыть: locus.oreshkin.me/z/1428
```

Тихие часы с 22 до 9. Всё, что накопилось ночью, приходит одним
сообщением в 9 утра:

```
Доброе утро! Пока тебя не было:
две новые задачи, один комментарий, один срок вышел
Посмотреть: locus.oreshkin.me/ya
```

# VIII. ОНБОРДИНГ

Требование: не двенадцать всплывающих шагов подряд. Так уже
делали к первой версии Локуса и это работало: **инструкция со скриншотами**,
по которой человек читает сам, плюс проводка по кнопкам там, где без неё
не разобраться

## Два слоя

**Слой первый, инструкция.** Отдельная страница в Полезном, читается как
статья: раздел за разделом, у каждого скриншот реального экрана и три-пять
строк текста. Открывается с любого места, листается без модального окна,
ссылку можно кинуть новому человеку в чат

**Слой второй, проводка.** Живые подсказки на самом экране, ровно четыре,
и только там, где механика неочевидна:

```
создание задачи    направление и тип, зачем они
спринт и срок      неделя главная, день внутри неё
подзадача          когда дробить и как уходит в чужое направление
ОКР                откуда берутся числа и почему их нельзя вписать руками
```

Подсказка показывается один раз, закрывается навсегда, вернуть из Личного
кабинета. Остальное человек читает в инструкции, когда ему нужно

## Разделы инструкции

```
1.  Что такое Локус       одна фраза про фокус и общую карту
2.  Моё пространство      что на мне на этой неделе
3.  Как создать задачу    кнопка есть на любом экране
4.  Направление и тип     зачем они и как выбирать
5.  Спринт и срок         неделя главная, день внутри неё
6.  Подзадачи             когда дробить и как уходит в чужое направление
7.  Раздел Задачи         три вида, фильтры, сортировка
8.  Люди и сотрудничества что такое статус и стадия
9.  ОКР                   цель, результат, веха, откуда берутся числа
10. Планёрка              зачем она и как собирается сама
11. Полезное              лента, рефлексия, принципы, анкеты команды
12. Личный кабинет        анкета, уведомления, настройки
```

## Тексты разделов

```
Что такое Локус
Локус это общая карта: задачи, люди, цели и движение по ним.
Нужен, чтобы держать фокус на важном, а не вспоминать, кто что обещал
[дальше]

Моё пространство
Здесь то, что на тебе на этой неделе. Открывается первым при входе.
Слева создаёшь задачу, справа смотришь свои
[дальше]

Как создать задачу
Кнопка создания есть на любом экране. Если создаёшь из клиента или
проекта, часть полей заполнится сама
[дальше]

Направление и тип
Направление отвечает, чья это работа. Тип отвечает, зачем она:
для клиента, для продукта, для цифры или внутренняя
[дальше]

Спринт и срок
Главное это неделя. День внутри недели ставится, только если он важен.
Незакрытая задача не пропадает, она остаётся с пометкой
[дальше]

Подзадачи
Большую работу дроби на подзадачи. Если подзадачу делает другое
направление, поменяй у неё направление: она уйдёт туда
[дальше]

Раздел Задачи
Все задачи команды. Три вида списка, фильтры по направлению,
человеку и статусу
[дальше]

Люди
Человек плюс направление это сотрудничество. Статус отвечает,
кто это: лид, клиент или архив. Стадия отвечает, где он в воронке
[дальше]

ОКР
Цель словами, результат числом. Число берётся из данных Локуса
или из замера, который кто-то вписал. У каждого числа видно источник
[дальше]

Планёрка
Собирается сама каждый день. Открываешь во вторник и идёшь
сверху вниз: что сделали, что дальше, что требует решения
[дальше]

Полезное
Лента команды, рефлексия по неделям, принципы работы и анкеты:
как с кем удобно работать
[дальше]

Личный кабинет
Твоя анкета, настройки уведомлений и вида. Онбординг можно
пройти заново отсюда
[готово]
```

После двенадцатого:

```
Готово! Локус твой. Пройти заново можно в Личном кабинете
```

## Онбординг новой фичи

Когда выходит что-то новое, человек узнаёт об этом тремя шагами:

```
1. уведомление       «В Локусе новое: контент-план по всем направлениям»
2. новость           открывается запись в Полезном: что появилось,
                     как работает, скриншот или короткое видео
3. кнопка            «Посмотреть вживую» открывает нужный экран
                     и подсвечивает новое место подсказкой
```

Подсказка на экране показывается один раз, с кнопкой «понятно»

## Старые четыре шага

Заменены двенадцатью. Четыре закрывали только первый вход, а не Локус

# IX. НОВОЕ В ЛОКУСЕ

Формат записи: что появилось, как работает, кнопка

```

Контент-план по всем направлениям

Медиа теперь видит публикации всех направлений на одном календаре.
Чипы сверху переключают направления, можно выбрать несколько
[показать]
```

Пишется от первого лица команды, без «мы рады сообщить»

# X. ЧТО СИСТЕМА ГОВОРИТ ПРО ПРОБЛЕМЫ

Факт и число, без оценки. Никаких «всё плохо» и «кризис»

```
Цель «Контакты» отстаёт на 18 процентов от календаря
Задача перенесена третий раз
В проекте «клиент А» нет закрытых задач три недели
С Игорем не общались 32 дня
У участницы Е на неделе 14 задач, обычно она закрывает 8
В Automy на этой неделе ни одной закрытой задачи
Замер по «Охвату» последний раз обновляли 15 октября
```

**Что система не говорит никогда:**

```
направление в кризисе
ты не справляешься
плохой результат
срочно!
```

Выводы делают люди на планёрке. Система даёт числа
